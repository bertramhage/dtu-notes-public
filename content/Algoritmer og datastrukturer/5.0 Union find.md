## Union find
Maintain a dynamic family of sets supporting the following operations:
- $Init(n)$: construct sets $\left\{ 0 \right\}, \left\{ 1 \right\}, \dots, \left\{ n-1 \right\}$
- $Union(i,j)$: forms the union of the two sets that contains $i$ and $j$. If $i \text{ and } j$ are in the same set nothing happens
- $Find(i)$: return a representative for the set that contains $i$

## Quick find
Maintain array $id[0..n-1]$ such that $id[i]$ = representation for $i$
- $Init(n)$: set elements to be their own representative
- $Union(i,j)$ if $Find(i) \neq Find(j)$ update representative for all elements in one of the sets
- $Find(i)$: return representative

**Time:** $Union: O(n), Find:O(1)$

## Quick union
Maintain each sets as a rooted tree
Store trees as array $p[0..n-1]$ such that $p[i]$ is the parent of $i$ and $p[root]$ = root.
- $Init(n)$: create $n$ trees with one element each
- $Union(i,j)$: if $Find(i)\neq Find(j)$ make the root of one tree the child of the root of the other tree
- $Find(i)$: follow path to root and return root

**Time:** $Union: O(n), Find:O(n)$

## Weighted quick union
Extension of quick union. Intuition balances the trees.
Maintain extra array $sz[0..n-1]$ such that $sz[i]$= the *size* of the subtree rooted at $i$
- $Init$: as before + initialize $sz[0..n-1]$
- $Find$: as before
- $Union(i,j)$: if $Find(i)\neq Find(j)$ make the root of the smaller tree the child of the root of the larger tree

**Time:** $Union: O(\log n), Find:O(\log n)$

>[!info] Lemma
>With weighted quick union the depth of a node is at most $\log_2n$


## Path compression
Compress path on $Find$. Make all nodes on the path children of the root
- No change in running time for a single $Find$, subsequent $Find$ becomes faster.
-  Works with both quick union and weighted quick union

![[Pasted image 20250512135314.png|600]]

>[!info] Theorem [Tarjan 1975]
>With path compression any sequence of $m$, $Find$ and $Union$ operations on $n$ elements take $O(n + m \alpha(m,n))$ time.
>- $\alpha(m,n)$ is the inverse of Ackermanns function. $\alpha(m,n) ≤ 5$ for any practical input.

>[!info] Theorem [Fredman-Saks 1985]
>It is not possible to support $m$, $Find$ and $Union$ operations $O(n + m)$ time.

## Dynamic connectivity
Maintain a dynamic graph supporting the following operations:
- $Init(n)$: create a graph $G$ with $n$ vertices and no edges
- $Connected(u,v)$: determine if $u$ and $v$ are connected
- $Insert(u,v)$: add edge $(u,v)$. We assume $(u,v)$ does not already exists.

### Implementation with union find
- $Init(n)$: Initialize a union find data structure with $n$ elements
- $Connected(u,v)$: $Find(u)==Find(v)$
- $Insert(u,v)$: $Union(u,v)$

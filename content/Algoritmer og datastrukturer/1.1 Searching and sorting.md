## Searching
> Given a sorted array A and number x, determine if x appears in the array.

**Example:**
![[Pasted image 20250213105807.png]]
#### Linear search
Check if each entry matches x
Time: $O(n)$

#### Binary search
Compare $x$ to the middle entry $m$ in $A$.
- If $A[m]$ = $x$ return $true$ and stop
- If $A[m]<x$ continue recursively on the right half
- If $A[m]>x$ continue recursively on the left half
Time: $O(\log(n))$

## Sorting
Given array $A[0..n-1]$ return array $B[0..n-1]$ with same values as $A$ but in sorted order.

**Example:**
![[Pasted image 20250213111132.png]]

#### Insertion sort
Start with an unsorted array $A$. Proceed left-to-right in $n$ rounds.
Round $i$:
- Subarray $A[0..i-1]$ is sorted
- Insert $A[i]$ into $A[0..i-1]$ to make $A[0..i]$ sorted

```
INSERTIONSORT(A, n) 
for i = 1 to n-1 
	j = i
	while j > 0 and A[j-1] > A[j] 
		swap A[j] og A[j-1] 
		j = j - 1
```

Time: $O(n^2)$

#### Merge sort
Split array in two halves. If $|A|≤1$ return $A$.
Sort each half recursively (using same algorithm)
Scan both arrays left-to-right, in each step:
- Insert smallest of the two entries in new array.
- Continue with the comparison using the next entry in the array with the smallest value.
- Repeat until input arrays are exhausted.

```
MERGESORT(A,i,j)
if i < j
	m =⎣(i+j)/2⎦ 
	MERGESORT(A,i,m) 
	MERGESORT(A,m+1,j) 
	MERGE(A, i, m, j)
```

Running time: $O(n\log n)$

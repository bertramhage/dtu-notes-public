**Priority queues:** Maintain dynamic set S supporting the following operations. Each element has key $x.key$ and satellite data $x.data$
Operations:
- $Max()$: Return element with largest key
- $ExtractMax()$: return and remove element with largest key
- $IncreaseKey(x,k)$: set $x.key=k$ (assume $k≥x.key$)
- $Insert(x)$: set $S=S\cup \left\{ x \right\}$

## Solutions

### Priority queues with linked lists
Maintain $S$ is a linked list
- $Max()$: linear search for largest key
- $ExtractMax$: Linear search for largest key, remove and return element
- $IncreaseKey(x,k)$: set $x.key=k$
- $Insert(x)$: add element to front of list
**Time**: $Max$ and $ExtractMax$ in $O(n)$, $IncreaseKey, Insert$ in $O(1)$ time.
**Space**: $O(n)$

### Priority queues with sorted linked lists
Maintain $S$ in a sorted linked list.
- $Max()$: return first element
- $ExtractMax()$: return and remove first element
- $IncreaseKey(x,k)$: set $x.key=k$ Linear search to move $x$ to correct position
- $Insert(x)$: lineaer search to insert $x$ at correct position
**Time:** $Max \text{ and } ExtractMax$ in $O(1)$ time, $IncreaseKey \text{ and } Insert$ in $O(n)$ time
**Space:** O(n)

### Priority queues with heaps
See [note on heaps](obsidian://open?vault=Noter&file=6.%20semester%2FAlgoritmer%20og%20datastrukturer%2F3.2%20Heaps)

**Max**
```
return H[1]
```

**ExtractMax**
```
r = H[1]
H[1] = H[n]
n = n -1
BubbleDown(1)
return r
```

**Insert(x)**
```
n = n+1
H[n] = x
BubbleUp(n)
```

**IncreaseKey(x, k)**
```
H[x] = k
BubbleUp(x)
```

**Time:** $Max$ in $O(1)$ time, $ExtractMax$, $IncreaseKey$ and $Insert$ in $O(\log n)$ time.

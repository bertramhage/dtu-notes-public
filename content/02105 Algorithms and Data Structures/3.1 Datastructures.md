## Stacks
Maintain dynamic sequence (stack) S supporting the following operations
- $Push(x)$: add $x$ to $S$
- $Pop()$: Remove and return the most recently added element in $S$
- $IsEmpty()$: return $true$ if $S$ is empty

Time: $Push$ in $O(1)$ time, $Pop$ in $O(1)$ time, $IsEmpty$ in $O(1)$ time.
Space: $O(n)$ space
## Queue
Maintain dynamic sequence (queue) Q supporting the following operations
- $Enqueue(x)$: Add $x$ to $Q$
- $Dequeue()$: remove and return the earliest added element in $Q$
- $IsEmpty()$: return true if $Q$ is empty

Time: $Enqueue$ in $O(1)$ time, $Dequeue$ in $O(1)$ time, $IsEmpty()$ in $O(1)$ time
Space: $O(n)$ space

## Dynamic arrays
Idea:
- Start with array of size 1
- $Push(x)$:
	- If array is full:
		- Allocate new array of twice the size
		- Move all elements to new array
		- Delete old array
![[Pasted image 20250306112752.png|300]]
Time: $Push$ is $O(n)$ time
Space: $O(n)$ space

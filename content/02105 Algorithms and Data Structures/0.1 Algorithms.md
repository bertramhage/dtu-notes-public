## Peaks
$A[i]$ is a peak if $A[i]$ is *as least as large* as it's neighbors.

#### Algorithm 1

```
PEAK1(A, n) 
if A[0] ≥ A[1] return 0 
for i = 1 to n-2 
	if A[i-1] ≤ A[i] ≥ A[i+1] return i 
if A[n-2] ≤ A[n-1] return n-1
```

Running time: $O(n)$
#### Algorithm 2
```
FINDMAX(A, n) 
max = 0 
for i = 0 to n-1 
	if (A[i] > A[max]) max = i 
return max
```
Running time: $O(n)$

#### Algorithm 3
```
PEAK3(A,i,j) 
m = ⎣(i+j)/2)⎦ 
if A[m] ≥ neighbors return m 
elseif A[m-1] > A[m] 
	return PEAK3(A,i,m-1) 
elseif A[m] < A[m+1] 
	return PEAK3(A,m+1,j)
```
Running time: $O(\log n)$

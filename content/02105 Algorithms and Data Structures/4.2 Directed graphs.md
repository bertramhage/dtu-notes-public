**Directed graphs**: Set of vertices pairwise joined by directed edges

>[!info] Lemma
>$$
>\sum_{v \in V}deg^-(v)=\sum_{v \in V}deg^+(v)=m
>$$

- **Path**. Is there a path from s to t? 
- **Shortest path**. What is the shortest path from s to t. 
- **Directed acyclic graph.** Is there a cycle in the graph?
- **Topological sorting.** Can we order the vertices such that all edges are directed in same direction? 
- **Strongly connected component.** Is there a path between all pairs of vertices? 
- **Transitive closure**. For which vertices is there a path from v to w?

## Representation

### Adjacency matrix
- 2D $n\times n$ array $A$
- $A[i,j]=1$ if $i$ points to $j$, 0 otherwise
**Space**: $O(n^{2})$
**Time**: $PointsTo$, $Insert(v,u)$ in $O(1)$, $Neighbors(v)$ in $O(n)$

### Adjacency lists
- Array $A[0..n-1]$
- $A[i]$ is a linked list of all nodes that $i$ points to
**Space**: $O\left( n+\sum_{v \in V}deg^+(v) \right)=O(n+m)$
**Time**: All operations in $O(deg(v))$ time

## Topological sorting
Ordering of vertices $v_0, v_1, \dots, v_{n-1}$ from left to right such that all edges are directed to the right.

![[Pasted image 20250320111211.png|600]]
>[!info] Lemma
>$G$ has topological sorting $\Leftrightarrow$ $G$ has vertex $v$ with in-degree 0 and $G-\left\{ v \right\}$ has topological sorting

### Solution 1
- Construct reverse graph $G^R$
- Search in adjacency list repr. of $G^R$ to find vertex $v$ with in-degree 0
- Remove $v$ and edges out of $v$
- Put $v$ leftmost
- Repeat

**Time**: $O(n^2)$

### Solution 2
- Maintain in-degree of every vertex + linked list of all vertices with in- degree 0.
- Find vertex v with in-degree 0.
- Remove v and edges out of $v$.
- Put $v$ leftmost.
- Repeat

**Time**: $O(n+m)$

## Directed acyclic graphs (DAG)
G is a DAG if it contains no (directed) cycles

Equivalence of DAGs and topological sorting. $G$ is a DAG $\Leftrightarrow$ $G$ has a topological sorting (see exercises).

## Strongly connected components
**Definition**: $v$ and $u$ are strongly connected if there is a path from $v$ to $u$ and $u$ to $v$.
**Definition**: A strongly connected component is a maximal subset of strongly connected vertices.

![[Pasted image 20250320112614.png|400]]
**Time**: We can compute the strongly connected components in a graph in $O(n + m)$ time. See CLRS 22.5

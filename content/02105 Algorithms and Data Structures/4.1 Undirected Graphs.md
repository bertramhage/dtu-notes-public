$V$: set of vertices
$E$: set of edges
$n=|V|, m=|E|$

**Path**: Sequence of vertices connected by edges
**Cycle**: Path starting and ending at the same vertex
**Degree**: $deg(v)$=the number of neighbors of $v$, or edges incident to $v$
**Connectivity**: A pair of vertices are connected if there exists a path between them

>[!info] Lemma 1
>$$
>\sum_{v\in V}deg(v)=2m
>$$

## Representation
For a graph $G$ with $n$ vertices and $m$ edges
- $Adjacent(v,u)$: determine if $u$ and $v$ are neighbors
- $Neighbors(v)$ return all neighbors of $v$
- $Insert(v,u)$: add the edge $(v,u)$ to $G$

### Adjacency matrix
Space: $O(n^2)$
Time: $Adjacent \text{ and } Insert$ in $O(1)$ time, $Neighbours$ in $O(n)$ time.

![[Pasted image 20250306110532.png|300]]
### Adjacency list
Array $A[0..n-1]$, $A[i]$ is a linked list of all neighbors of $i$
Space: $O(n+m)$
Time: $Adjacent, Neighbors, Insert$ in $O(deg(v))$ time

## Depth-first search
**Intuition**:
- Explore from $s$ in some direction, until we read dead end.
- Backtrack to the last position with unexplored edges
- Repeat

**Discovery time**: First time a vertex is visited.
**Finish time**: Last time a vertex is visited.

Time: $O(n+m)$

## Breadth-first search (BFS)
**Intuition**:
- Initialize a queue $Q$
- Explore, starting from $s$ all unmarked vertices and add them to $Q$
- Dequeue $s$ and mark all unmarked vertices from the next item in $Q$ adding them to the queue
- Continue until queue is empty

>[!info] Lemma 2
>BFS finds the length of the shortest path from $s$ to all other vertices

Time: $O(n+m)$

## Bipartite graphs
**Definition**: A graph is bipartite if and only if all vertices can be colored red and blue such that every edge has exactly one red endpoint and one blue endpoint.

![[Pasted image 20250306113920.png|300]]

**Equivalent definition**: A graph is bipartite if and only if its vertices can be partitioned into two sets $V_1$ and $V_2$ such that all edges go between $V_1$ and $V_2$.

>[!info] Lemma 3
>A graph $G$ is bipartite if and only if all cycles in $G$ have even length

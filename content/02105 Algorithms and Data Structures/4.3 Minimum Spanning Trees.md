**Weighted graphs**: Weight on each edge $e$ in $G$
**Spanning tree**: Subgraph $T$ of $G$ over all vertices that is connected and acyclic
**Minimum spanning tree (MST)** Spanning tree of minimum total weight

## Properties of MST

**Asumption:**
All edge weights are distinct and $G$ is connected $\implies$ MST exists and is unique

**Cut:**  a partition of the vertices into non-empty sets
**Cut edge**: edge crossing the cut

>[!info] Cut property
>For any cut, the lightest cut edge is in the MST

>[!info] Cycle property
>For any cycle, the heaviest edge is *not* in the MST

## Prim's algorithm
Greedy algorithm
- Grow a tree $T$ from some vertex $s$
- In each step, add lightest edge with one endpoint in T.
- Stop when $T$ has $n-1$ edges.

### Implementation
Maintain vertices outside $T$ in priority queue
- Key of vertex $v$= weight of lightest cut edge ($\infty$ if no cut edge)
- In each step:
	- Find lightest edge = $Extract$-$Min$
	- Update weight of the neighbours of new vertex with $Decrease$-$Key$

**Time**: $Extract$-$Min$: $n$, $Insert: n$, $O(m): Decrease$-$Key$
Total time with min-heap: $O(m\log n)$

## Kruskal's algorithm
Also a greedy algorithm
- Consider edges from lightest to heaviest
- In each step, add edge to $T$ if it does *not* create a cycle
- Stop when $T$ has $n-1$ edges

### Implementation
- Maintain edges in a data structure for dynamic connectivity
- In each step:
	- Check if an edge creates a cycle = $Connected$
	- Add new edge = $Insert$

**Time**: $Init: 1$, $Connected: m$, $Insert: n$
Total time: $O(m\log n)$

## Statistical Learning

**Statistical learning** involves a set of approaches for estimating an unknown function *f*.

We assume a relationship between a quantitative response variable *Y* and a set of predictor variables *X* = (*X*₁, *X*₂, ..., *X*ᵣ) of the form:
$$Y = f(X) + \epsilon$$
where:
-   ***f*** is a fixed but unknown function of the predictors.
-   ***ε*** is a random error term with a mean of zero, independent of X. The error term accounts for unmeasured variables and measurement error.



> [!info] Why estimate f?
> -   **Prediction**: To predict the value of *Y* for a given set of inputs *X* using *Ŷ* = *f̂*(*X*). In prediction, *f̂* can often be treated as a "black box" as long as it provides accurate predictions.
> -   **Inference**: To understand the relationship between *X* and *Y*. This includes identifying which predictors are most important and the nature of their relationship with the response (e.g., linear, non-linear).

### Prediction Accuracy
The accuracy of a prediction *Ŷ* depends on two types of error:
-   **Reducible Error**: This error comes from the fact that our estimate *f̂* is not a perfect estimate of the true function *f*. We can reduce this error by using better statistical learning methods.
-   **Irreducible Error**: This error is associated with the random error term *ε* and cannot be reduced, no matter how well we estimate *f*. It represents the upper bound on the accuracy of our prediction.

### Methods for Estimating f
There are two main approaches to estimate the function *f*:
1.  **Parametric Methods**: These methods make an assumption about the functional form of *f*, such as assuming it is linear. The problem is then reduced to estimating a set of parameters (e.g., β₀, β₁ in linear regression).
2.  **Non-parametric Methods**: These methods do not make explicit assumptions about the form of *f* and can fit a wider range of shapes. Examples include decision trees and K-nearest neighbors.

## Model Performance

### Assessing Model Accuracy
In a regression setting, the most common measure of model accuracy is the **Mean Squared Error (MSE)**.

> [!info] Mean Squared Error (MSE)
> The MSE is calculated as:
> $$
> MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{f}(x_i))^2
> $$
> where *f̂*(*x*ᵢ) is the prediction for the *i*-th observation.
> -   **Training MSE**: Calculated on the data used to train the model.
> -   **Test MSE**: Calculated on new, unseen data. This is the more interesting metric as it indicates how well the model generalizes.

A lower training MSE does **not** guarantee a lower test MSE. A model can be overfit to the training data, capturing noise instead of the underlying pattern, which leads to poor performance on test data.



### The Bias-Variance Trade-Off
The expected test MSE for a given point *x*₀ can be decomposed into three components: the bias squared, the variance, and the irreducible error.

$$\text{Expected Test MSE} = \text{Bias}(\hat{f}(x_0))^2 + \text{Var}(\hat{f}(x_0)) + \text{Var}(\epsilon)$$

> [!info] Bias vs. Variance
> -   **Bias**: The error introduced by approximating a real-life, complex problem with a simpler model. More flexible models have lower bias.
> -   **Variance**: The amount by which our estimate *f̂* would change if we estimated it using a different training dataset. More flexible models have higher variance.

There is a fundamental trade-off: as a model's flexibility increases, its bias tends to decrease, but its variance increases. The goal is to find a model that has both low bias and low variance.

## Linear Regression

### Bivariate Linear Regression
The simplest model assumes a linear relationship between a single predictor variable *X* and the response *Y*.
$$Y = \beta_0 + \beta_1X + \epsilon$$
-   β₀ is the intercept.
-   β₁ is the slope.

### Ordinary Least Squares (OLS)
OLS is a method used to estimate the parameters β₀ and β₁. It finds the line that minimizes the **sum of squared residuals** (the differences between the observed values and the predicted values).

> [!example] OLS Estimates
> The OLS parameter estimates, denoted *β̂*₀ and *β̂*₁, are calculated as:
> $$
> \hat{\beta}_1 = \frac{\sum_{j=1}^{n}(x_j - \bar{x})(y_j - \bar{y})}{\sum_{j=1}^{n}(x_j - \bar{x})^2}
> $$>$$
> \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}
> $$

### Multivariate Linear Regression
This extends bivariate regression to include multiple predictor variables (*X*₁, *X*₂, ..., *X*ᵣ).
$$Y = \beta_0 + \beta_1X_1 + \cdots + \beta_rX_r + \epsilon$$

In matrix notation, the model is expressed as:
$$y = X\beta + \epsilon$$The OLS solution in matrix form is:$$\hat{\beta} = (X^T X)^{-1}X^T y$$

## Model Improvement & Regularization

When the number of observations *n* is not much larger than the number of predictors *p*, OLS estimates can have high variance. Regularization methods can help by constraining the model coefficients, which reduces variance at the cost of a small increase in bias.

### Ridge Regression
Ridge regression adds a penalty term to the OLS objective function that is equal to the sum of the squared coefficients.
$$S = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{p}\beta_j^2$$
-   The tuning parameter λ controls the strength of the penalty.
-   Ridge regression shrinks coefficients towards zero but will never set them to exactly zero.

### The Lasso
The Lasso (Least Absolute Shrinkage and Selection Operator) uses a different penalty term.
$$S = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{p}|\beta_j|$$
-   Unlike Ridge, the Lasso can shrink some coefficients to exactly zero, effectively performing variable selection.
-   This makes Lasso models easier to interpret.

> [!info] Scaling for Regularization
> Standard OLS estimates are scale equivariant, meaning the final prediction doesn't change if you scale a predictor. However, for Ridge and Lasso, the penalty term makes the model sensitive to the scale of the predictors. Therefore, it's **important to standardize the predictors** before applying these methods.

## Data Preprocessing

### Feature Scaling
Two common methods are:
-   **Standardization**: Transforms data to have a mean of 0 and a standard deviation of 1.
    $$
    \tilde{x}_{ij} = \frac{x_{ij} - \bar{x}_j}{\sigma_{x_j}}
    $$
-   **Normalization**: Scales data to a range between 0 and 1.
    $$
    \tilde{x}_{ij} = \frac{x_{ij} - x_{\text{MIN}_j}}{x_{\text{MAX}_j} - x_{\text{MIN}_j}}
    $$

### Handling Categorical Predictors
To include a categorical variable in a linear model, we create **dummy variables**.
-   For a categorical variable with *k* levels, we create *k*-1 dummy variables.
-   Each dummy variable is binary (0 or 1), indicating the presence or absence of a specific category level.

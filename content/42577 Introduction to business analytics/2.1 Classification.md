## Introduction to Classification

Classification is a supervised learning task for predicting a **discrete** (categorical) dependent variable. This is different from regression, which predicts a **continuous** variable.

---
## Logistic Regression

Linear regression is unsuitable for classification because it predicts values in the range $(-\infty, \infty)$, while classification problems often require predicting a probability, which must be in the range $[0, 1]$.

### Binary Logistic Regression

This model handles problems with two classes, which we can label as `0` and `1`. We aim to model the probability that an observation belongs to class 1, i.e., $p(Y=1)$.

To link the linear model output $(-\infty, \infty)$ with probability $[0, 1]$, we use a transformation.

>[!info] The Logit Transformation
>1. **Odds Ratio**: The ratio of the probability of an event happening to it not happening.
>   $$ \text{odds} = \frac{p(Y=1)}{1-p(Y=1)} = \frac{p}{1-p} $$
>   The odds range from $[0, \infty)$.
>2. **Logit Function (Log-Odds)**: The natural logarithm of the odds.
>   $$ \text{logit}(p) = \ln\left(\frac{p}{1-p}\right) $$
>   The logit function maps probabilities from $[0, 1]$ to the entire real number range $(-\infty, \infty)$.

We can now model the logit as a linear function of the independent variables ($x$):
$$ \ln\left(\frac{p}{1-p}\right) = \beta^T x $$

### The Sigmoid Function
To convert the output of the linear model back into a probability, we use the **logistic sigmoid function**, which is the inverse of the logit.

$$
p(Y=1) = \frac{1}{1 + e^{-\beta^T x}}
$$

This function produces an 'S'-shaped curve, mapping any real number to a value between 0 and 1.

### Evaluating Classifiers

Performance is measured using a **confusion matrix**, which compares the actual classes to the predicted classes.

>[!info] Key Performance Metrics
>- **Accuracy**: The proportion of all predictions that were correct.
>  $$ \text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN} $$
>- **Precision**: The proportion of positive predictions that were actually correct. High precision means a low false positive rate.
>  $$ \text{Precision} = \frac{TP}{TP+FP} $$
>- **Recall (Sensitivity)**: The proportion of actual positives that were identified correctly. High recall means a low false negative rate.
>  $$ \text{Recall} = \frac{TP}{TP+FN} $$
>- **F1 Score**: The harmonic mean of precision and recall. It's a useful single metric, especially if the classes are imbalanced.
>  $$ F1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} $$

## Support Vector Machines (SVM)

SVMs find an optimal **hyperplane** that separates the classes in the feature space. For mathematical convenience, classes are labeled as `{-1, 1}`.

### Maximal Margin Classifier
The best hyperplane is the one that has the largest **margin**, which is the distance between the hyperplane and the closest data points from either class. The goal is to maximize this separation.

>[!info] Support Vectors
>The data points that lie on the edge of the margin are called **support vectors**. The position of the hyperplane is determined *only* by these points, which makes the SVM model robust.


### Soft Margin & Regularization
For data that is not perfectly linearly separable, the **Support Vector Classifier** (or soft margin SVM) is used. It allows some data points to be misclassified or to fall inside the margin to find a better overall fit.

A **regularization parameter `C`** controls the trade-off:
- **Large `C`**: Prioritizes classifying all points correctly, leading to a smaller margin and potential overfitting.
- **Small `C`**: Allows for more misclassifications, leading to a larger margin and potential underfitting.

### The Kernel Trick for Non-Linear Data
When a linear boundary isn't sufficient, the **kernel trick** can be used.

>[!info] Kernel Trick
>The kernel trick implicitly maps the data into a higher-dimensional space where a linear separator can be found. It does this efficiently by using a **kernel function** $K(x_i, x_j)$, which calculates the dot product of the data points in the higher-dimensional space without ever explicitly performing the transformation.

The decision function uses this kernel: $f(x_i) = \beta_0 + \sum_{j \in S} \alpha_j y_j K(x_i, x_j)$, where $S$ is the set of support vectors.

### Common Kernel Functions
>[!example] Kernel Types
>- **Linear Kernel**: $K(x_i, x_j) = \langle x_i, x_j \rangle$
>  - Used for linearly separable data.
>- **Polynomial Kernel**: $K(x_i, x_j) = (1 + \langle x_i, x_j \rangle)^d$
>  - Creates a decision boundary of polynomial degree `d`.
>- **Radial Basis Function (RBF) Kernel**: $K(x_i, x_j) = \exp(-\gamma ||x_i - x_j||^2)$
>  - A very flexible kernel that can create complex, non-linear boundaries. The `gamma` parameter controls the influence of each point. A high `gamma` can lead to overfitting.

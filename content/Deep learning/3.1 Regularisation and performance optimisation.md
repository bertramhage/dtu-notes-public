## Explicit regularisation
Adding explicit terms to the loss function that favour certain parameter choices.
### Weight decay
Add a penalty term for complexity to the loss
$$
L'(\phi)=L(\phi)+g(\phi)
$$
where $g$ is solely a function of parameters $\phi$ (excl. biases)

**$\mathcal{l}^{2}$-regularisation**
$$
g(\phi)=\frac{\lambda}{2}\mid\mid \phi\mid\mid^{2}=\frac{\lambda}{2}\sum\phi^{2}_j
$$
where $\lambda$ controls the strength of the regularisation.

**$\mathcal{l}^1$-regularisation**
$$
g(\phi)=\frac{\lambda}{2}\mid\mid \phi\mid\mid_1=\frac{\lambda}{2}\sum|\phi|
$$
## Implicit regularisation
Algorithms inherently favour certain solutions over others, even without explicit regularisation terms added to the loss function. This is due to the *finite* step size.

- **Gradient descent**: Penalises large gradients
- **SDG**: In addition penalises large variance gradients

## Heuristics to improve performance
#### Early stopping
- Monitor *validation* performance
- Stop when it starts to deteriorate
#### Data augmentation
- Eg. cropping all combinations of 1-pixel edges in an image gives you 9 times the data
#### Injecting data noise
- Inject random noise during training
- Can be applied to input data, hidden activations or weights
#### Ensemble methods
- Train several model and
	- average output (regression) or
	- average probabilities (/or maj. voting) (classification)
- Known from random forest
	- Bagging trees + feature subsampling
	- Bagging: resampled data with replacement
- Make individual models different by
	- Varying random seed
	- Varying model architecture
	- Varying hyperparameters and algorithms
	- Varying data (dropping examples or dimensions)
#### Dropout
- For each input $x$ randomly drop hidden nodes with probability $\rho=0.5$
- At test time:
	- Use all nodes but multiply weights by $\rho$ or
	- Use as an ensemble

#### Gradient clipping
- To avoid vanishing and/or exploding gradients
- Clip the magnitude of the gradient

## Residual networks
- For especially very deep networks we may (still after applying above regularisation techniques) have problems with gradient flow
- Residual (skip) connections help by adding an *identity path*: 
$$
\mathbf{h}^{(\ell)}=\mathbf{h}^{(\ell-1)}+f_{\phi_l}^{(\ell)}(\mathbf{h}^{(\ell-1)})
$$
- Allows gradients to flow directly through the network

## Batch normalisation

- Keeping activations and gradients well-scaled
- Improves learning
- Allows bigger learning rates (5$\times$ and 30$\times$)

**Invariance and equivalence**
In images we want translational equivalence.

A function $f$ is invariant to a transformation $t$ if
$$
f(t(\mathbf{x}))=f(\mathbf{x}).
$$
A function $f$ is equivariant to a transformation $f$ if
$$
f(t(\mathbf{x}))=t(f(\mathbf{x})).
$$

The output dimensionality of a Convolutional Neural Network (CNN) layer is a tensor typically given in the format (**output channels**, **output height**, **output width**).

While the sources thoroughly describe the input parameters and the mechanism of the convolution operation, they do not provide a single, explicit mathematical formula (such as those using the floor function) that combines all these variables to calculate the output dimensions. However, based on the definitions provided, the output dimensions are determined as follows:

### 1. Output Channels

The dimension corresponding to the channels in the output tensor is equal to the number of filters (`channels_out`) used in the convolutional layer.

If the layer has $C_i$ input channels and produces $C_o$ output channels, this requires $C_o$ distinct convolutional kernels.

$$
\mathbf{\text{Output Channels}} = \text{channels}_{out}
$$

### 2. Output Height and Width (Spatial Dimensions)

The calculation of the output height and width depends on the relationship between the input spatial dimensions (`height`, `width`), the filter size (`filter_height`, `filter_width`), the padding, and the stride. The convolutional layer calculates an output value for each position where the kernel is placed across the input.

For a dimension $D$ (either Height or Width), the calculation requires:

- **Input Dimension ($D_{in}$):** The input height or width.
- **Filter Size ($F$):** The filter height (`filter_height`) or width (`filter_width`).
- **Padding ($P$):** The padding applied to that dimension. **Zero-padding** is commonly used, assuming values outside the input range are zero to manage the edges of the input where the kernel extends beyond the valid range.
- **Stride ($S$):** The step size used to shift the kernel across the input. A stride greater than one reduces the number of outputs generated.

The general formula commonly used in convolution arithmetic to calculate the resulting output size ($D_{out}$) for a given dimension is:

$$\mathbf{D_{out}} = \left\lfloor \frac{D_{in} - F + 2P}{S} \right\rfloor + 1$$

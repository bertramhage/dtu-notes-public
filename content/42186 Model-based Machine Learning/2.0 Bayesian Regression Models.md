**Regression**:
Predict response variable $y$ from a collection of $D$ predictor variables $x_1,x_2,\dots,x_D$.
$y$ - target
$x_d$ - features, covariates, explanatory or independent variables
$y=f(x_1,\dots,x_d,\dots x_D)$

## Linear relationship
$$
y=\beta_0+\sum_{d=1}^{D} \beta_dx_d+\epsilon=\beta_0+\mathbf{\beta}^\top\mathbf{x} \, +\epsilon,\quad \epsilon \sim \mathcal{N}(0,\sigma^{2})
$$
$\implies \mathcal{N}(y|\beta ^\top\mathbf{x},\sigma^{2})$

**Graphical representation**
![[Pasted image 20260304131846.png|100]]
**Generative process**
1. For $n=1,\dots N$ do:
	a. Draw target $y_n\sim \mathcal{N(y_n)|\beta ^\top\mathbf{x}_n,\sigma^{2}}$

**Factorized**
$$
p(\mathbf{y}|\mathbf{X},\beta, \sigma)=\underbrace{ \prod_{n=1}^{N} \mathcal{N}(y_n|\beta ^\top\mathbf{x_n}, \sigma^{2}) \, }_{ \text{Likelihood} }
$$
where $\mathbf{y}=\{ y_n \}_{n=1}^N$, $\mathbf{X}=\{ \mathbf{x}_n \}_{n=1}^N$, $\beta$ are the model parameters and $\sigma$ is fixed.

**Maximum likelihood estimation (MLE)**
$$
\hat{\beta}=\operatorname*{arg\,max}_\beta \log \prod_{n=1}^{N} \mathcal{N}(y_n|\beta ^\top\mathbf{x_n},\sigma^{2})=\operatorname*{arg\,max}_\beta \sum_{n=1}^{N} \log \mathcal{N}(y_n|\beta ^\top\mathbf{x}_n,\sigma^{2}) \,  \, 
$$

## Bayesian regression
Before observing any data, the Bayesian approach captures assumptions about the parameters in the form of a prior probability.

### Adding priors
We model $\beta$ as a random variable and assign it a prior distribution
$$
p(\beta)=\mathcal{N}(\beta|\mathbf{\mu,\Sigma}).
$$

A typical choice is a Gaussian with zero mean and diagonal covariance matrix
$$
p(\beta)=\mathcal{N}(\beta|\mathbf{0}, \lambda \mathbf{I})
$$
where too large $\lambda$ can lead to overfitting and small $\lambda$ can lead to underfitting.

### Bayesian linear regression model

**Graphical representation**
![[Pasted image 20260304133637.png|150]]
**Generative process**
1. Draw coefficient $\beta \sim \mathcal{N(\beta|\mathbf{0}, \lambda \mathbf{I})}$
2. For each feature vector $\mathbf{x}_n$
	a. Draw target $y_n\sim \mathcal{N(y_n|\beta ^\top\mathbf{x}_n,\sigma^{2})}$

**Factorization**
$$
\begin{aligned}
p(\mathbf{y},\beta|\mathbf{X},\sigma,\lambda)&=p(\beta|\lambda)\prod_{n=1}^{N} p(y_n|\beta ,\mathbf{x}_n,\sigma) \\
&=\mathcal{N}(\beta|\mathbf{0},\lambda \mathbf{I})\times \prod_{n=1}^{N} \mathcal{N}(y_n|\beta ^\top\mathbf{x}_n,\sigma^{2}) \,  \, 
\end{aligned}
$$

### Inference
Goal: Compute posterior distribution on $\beta$
$$
\underbrace{ p(\beta|\mathbf{y,X},\sigma,\lambda) }_{ \text{posterior} }
\propto \underbrace{ \mathcal{N}(\beta|\mathbf{0}, \lambda \mathbf{I}) }_{ \text{prior} }
\times \underbrace{ \prod_{n=1}^{N} \mathcal{N}({y_n|\beta ^\top\mathbf{x}_n,\sigma^{2}} \, ) }_{ \text{likelihood} }
$$

#### Maximum-a-posteriori estimation (MAP)
Maximize  the log joint probability of the model
$$
\begin{aligned}
\hat{\beta}&=\operatorname*{arg\,max}_\beta \log \left( \mathcal{N}(\beta|\mathbf{0},\lambda \mathbf{I})\prod_{n=1}^{N} \mathcal{N}(y_n|\beta ^\top\mathbf{x}_n,\sigma^{2}) \,  \right)  \\
&=\operatorname*{arg\,max}_\beta \left( \log \mathcal{N}(\beta|\mathbf{0}, \lambda \mathbf{I})+\sum_{n=1}^{N} \log \mathcal{N}(y_n|\beta ^\top\mathbf{x}_n,\sigma^{2}) \,  \right) 
\end{aligned}
$$
### Poisson regression
As with the Gaussian, make the rate of the Poisson linearly dependent on the features $\mathbf{x}$
$$
y_n\sim \text{Poisson}(y_n|e^{\beta ^\top\mathbf{x}_n})
$$
where $e^{b^\top\mathbf{x}_n}\in(0,\infty)$ ensures non-negativity.

**Factorization** becomes
$$
\begin{aligned}
p(\mathbf{y},\beta|\mathbf{X},\sigma,\lambda)&=p(\beta|\lambda)\prod_{n=1}^{N} p(y_n|\beta ,\mathbf{x}_n,\sigma) \\
&=\underbrace{ \mathcal{N}(\beta|\mathbf{0},\lambda \mathbf{I}) }_{ \text{prior} }\times \underbrace{ \prod_{n=1}^{N} \text{Poisson}(y_n|e^{\beta ^\top\mathbf{x}_n}) }_{ \text{likelihood} } \,  \, 
\end{aligned}
$$

## Non-linear regression
For
$$
y_n=f(\mathbf{x}_n)+\epsilon
$$
we can assume $f(\mathbf{x}_n)$ to be a complex neural network.
- Variables in a PGM can be part of the input to a NN
- Output variables of a NN can be part of a PGM

### Neural networks in PGMs
A simple example
$$
y_n=f_{\text{linear}}(\mathbf{x}_n)+f_{\text{NN}}(\mathbf{u}_n)+\epsilon
$$
where $f_{\text{linear}}(\mathbf{x}_n)=\beta ^\top\mathbf{x}_n$ and $f_{\text{NN}}(\mathbf{u}_n)$ is a NN with parameters denoted by $\mathbf{\theta}$.

**Generative process**
1. Draw linear coefficients $\beta \sim \mathcal{N}(\beta|\mathbf{0}, \lambda \mathbf{I})$
2. Draw NN parameters $\theta \sim \mathcal{N}(\theta|\mathbf{0},\tau \mathbf{I})$
3. For the $n^{th}$ observation
	a. Draw target $y_n\sim \mathcal{N}(y_n|f_{\text{linear}}(\mathbf{x}_n)+f_{\text{NN}}(\mathbf{u}_n), \sigma^{2})$

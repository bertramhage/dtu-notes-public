Let $y_t$ denote the occupancy rate in that sensor at time $t$

## Basic Markov models
Assume that each $y_t$ depends only on $y_{t-1}$
$$
p(y_1,\dots,y_T)=p(y_1)\prod_{t=2}^{T} p(y_t|y_{t-1}) \, 
$$
## Autoregressive (AR) models
Assume that each $y_t$ is a linear function of the $M$ previous observations (+ noise)
$$
y_t=\beta_1y_{t-1}+\beta_2y_{t-2}+\dots+\beta_M y_{t-M}+\epsilon
$$
where $\epsilon \sim \mathcal{N}(0,\sigma^{2})$.

**AR1**:
![[Pasted image 20260318131606.png|400]]
Generative process:
1. Draw transition coefficient $\beta \sim \mathcal{N}(\beta|0,\lambda)$
2. Draw first observation $y_1\sim \mathcal{N}(y_1|\mu_0,\sigma^{2}_0)$
3. For each time $t \in \{ 2,\dots,T \}$
	1. Draw observation $y_t\sim \mathcal{N}(y_t|\beta y_{t-1},\sigma^{2})$

**AR2**:
![[Pasted image 20260318131825.png|400]]
Generative process:
1. Draw transition coefficient $\beta \sim \mathcal{N}(\beta|\mathbf{0},\lambda \mathbf{I})$
2. Draw first observation $y_1\sim \mathcal{N}(y_1|\mu_0,\sigma^{2}_0)$
3. Draw second observation $y_2\sim \mathcal{N}(y_2|\beta_1y_{t-1},\sigma^{2})$
4. For each time $t \in \{ 3,\dots,T \}$
	1. Draw observation $y_t\sim \mathcal{N}(y_t|\beta y_{t-1},\sigma^{2})$

### Problems with AR models
If $\{ y_{t-1},\dots,y_{t-M}\}$ are themselves noisy observation (eg. due to measurement noise in sensors), we build up noise over time. We want to decouple the noise between observations.

## State-space models (SSMs)
Introduce hidden variables $\{ \mathbf{h}_{1},\dots,\mathbf{h}_T \}$ from which the observations $\{ y_1,\dots,y_T \}$ are assumed to be generated.

$y_t$ is assumed to be *independent* from all other variables given $\mathbf{h}_t$.

![[Pasted image 20260318132604.png|400]]

Requires two probability distributions
- Transition provability: $p(\mathbf{h}_t|\mathbf{h}_{t-1})$
- Observation (or emission) probability: $p(y_t|\mathbf{h}_t)$

### Linear dynamical systems (LDSs)
Assume linear Gaussians
$$
\begin{aligned}
\mathbf{h}_t&\sim \mathcal{N}(\mathbf{h}_t|\mathbf{Bh}_{t-1},\mathbf{R}) \\
y_t&\sim \mathcal{N}(y_t|\mathbf{c}^\top\mathbf{h}_t,\sigma^{2})
\end{aligned}
$$
- $\mathbf{B}, \mathbf{R}, \mathbf{c}$ and $\sigma$ are often trated as parameters rather than random variables (MLE or MAP)
- Fully Bayesian approach: Assign priors to $\mathbf{B}, \mathbf{R}, \mathbf{c}, \sigma$ and use Bayesian inference to compute respective posteriors

#### AR models as LDSs
By appropriately defining the latent states, many popular time-series models can be cast as an LDS

E.g. an autoregressive model of order k (AR-k) can be written as:

$$\underbrace{ \begin{pmatrix} h_t \\ h_{t-1} \\ \vdots \\ h_{t-k+1} \end{pmatrix} }_{ \mathbf{h}_t } = \underbrace{ \begin{pmatrix} \beta_1 & \beta_2 & \cdots & \beta_k \\ 1 & 0 & 0 & 0 \\ 0 & \ddots & 0 & 0 \\ 0 & 0 & 1 & 0 \end{pmatrix} }_{ \mathbf{B} } \underbrace{ \begin{pmatrix} h_{t-1} \\ h_{t-2} \\ \vdots \\ h_{t-k} \end{pmatrix} }_{ \mathbf{h}_{t-1} } + \begin{pmatrix} \tau_t \\ 0 \\ \vdots \\ 0 \end{pmatrix}$$
with the emission probability defined as
$$y_t = \underbrace{(1 \quad 0 \quad \cdots \quad 0)}_{\mathbf{c}} \mathbf{h}_t + \epsilon_t$$
where $\tau_t \sim \mathcal{N}(0, r)$ and $\epsilon_t \sim \mathcal{N}(0, \sigma^2)$.

#### Poisson LDSs
A Pousson distribution could be another choice for emission probability (eg forecasting arrivals/departures):
$$
y_t\sim \text{Poisson}(y_t|\exp(\mathbf{c}^\top\mathbf{h_t}))
$$
#### LDSs with inputs
Let $x_t$ be external inputs at time $t$

$$
\mathbf{h}_t\sim \mathcal{N}(\mathbf{h}_t|\mathbf{Bh}_{t-1}+\mathbf{Wx}_t,\mathbf{R})
$$
or:
$$
y_t\sim \mathcal{N}(y_t|\mathbf{c}^\top\mathbf{h}_t+\mathbf{Wx}_t,\sigma^{2})
$$

#### Extended Kalman filter (EKF)
Relax the assumption of linear relations between states and from state to observations – to arbitrary differentiable functions $f$, $g$ (eg. neural networks)
$$
\begin{aligned}
\mathbf{h}_t&\sim \mathcal{N}(\mathbf{h}_t|f(\mathbf{h}_{t-1},\mathbf{x}_t),\mathbf{R}) \\
y_t&\sim \mathcal{N}(y_t|g(\mathbf{h}_t), \sigma^{2})
\end{aligned}
$$
#### Switching LDSs
Introduce multiple latent state chains: $\{ \mathbf{h}_1^1,\dots,\mathbf{h}_T^1 \}\dots \{ \mathbf{h}_1^M ,\dots,\mathbf{h}_T^M\}$ and let a discrete latent variable $z_t$ select one of the latent state chains to be active, at each $t$, to produce an observation $y_t$.

### Hidden Markov models (HMM)
Discrete analog of the LDS.

Let $h_t$ and $y_t$ be discrete random variables. 

Transition probabilities $p(h_t|h_{t-1}, \mathbf{B})$ for $h_t\in\{ 1,\dots,K \}$ are specified using a $K\times K$ matrix $\mathbf{B}$, where $b_{ij}$ denotes the probability of transition to state $j$ given the current state is $i$.

Emission probabilities $p(y_t|h_t,\mathbf{C})$ for $y_t\in\{ 1,\dots,V \}$ can be specified using a $K\times V$ matrix $\mathbf{C}$.

Thus,
$$
h_t\sim \text{Categorical}(h_t|\mathbf{b}_{h_{t-1}})
$$
and
$$
y_t\sim \text{Categorical}(y_t|\mathbf{c}_{h_t}).
$$
Use the conjugate prior Dirichlet.

**Generative process**:
1. For each possible hidden state value $k\in\{ 1,\dots,K \}$
	1. Draw transition probabilities $\mathbf{b}_k\sim \text{Dirichlet}(\mathbf{b}_k|\alpha)$
	2. Draw emission probabilities $\mathbf{c}_k\sim \text{Dirichlet}(\mathbf{c}_k|\gamma)$
2. For each time $t\in\{ 1,\dots,T \}$
	1. Draw new hidden state $h_t\sim \text{Categorical}(h_t|\mathbf{b}_{h_{t-1}})$
	2. Draw observation $y_t\sim \text{Categorical}(y_t|\mathbf{c}_{h_t})$

## Multivariate state-space models
$\mathbf{y}_t=(y_{t}^1,\dots,y_t^K)$ is now a vector and
$$
\begin{aligned}
\mathbf{h}_t&\sim \mathcal{N}(\mathbf{h}_t|\mathbf{Bh}_{t-1},\mathbf{R}) \\
\mathbf{y}_t&\sim \mathcal{N}(\mathbf{y}_t|\mathbf{Ch}_t,\mathbf{\Sigma})
\end{aligned}
$$
- $\mathbf{\Sigma}=\sigma \mathbf{I}$ assumes a single variance for all elements of $\mathbf{y}$
- $\mathbf{\Sigma}=\text{diag}(\mathbf{\sigma})$ assumes a different variance for each element of $\mathbf{y}$ ($\mathbf{\sigma}=(\sigma_1,\dots,\sigma N)$).

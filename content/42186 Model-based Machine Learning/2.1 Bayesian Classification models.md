Given features $\mathbf{x}_n$ and latent *discrete* variables $y_n$ we can represent our model for the entire dataset as

![[Pasted image 20260311131647.png|200]]
## Binary logistic regression
For $y_n\in \{ 0,1 \}$ we use a $\text{Sigmoid}(z): \mathbb{R}\to [0,1]$ where we define $z_n=\beta ^\top\mathbf{x}_n$, we interpret $\text{Sigmoid}(z_n)$ as $p(y_n=1)$.

**Generative process**:
1. Draw coefficients $\beta \sim \mathcal{N}(\beta|\mathbf{0},\lambda \mathbf{I})$
2. For each feature vector $\mathbf{x}_n$
	1. Draw class $y_n\sim \text{Bernoulli}(y_n|\text{Sigmoid}(\beta ^\top\mathbf{x}_n))$

**Factorization**:
$$
p(\mathbf{y}, \beta|\mathbf{X}, \lambda)=p(\beta|\lambda)\times \prod_{n=1}^{N} p(y_n|\beta, \mathbf{x}_n) \, 
$$
where $p(y_n|\beta,\mathbf{x}_n)$ follows a Bernoulli distribution.

## Multi-class logistic regression
The generalization of the logistic sigmoid to multiple outputs is the softmax, utilizing a set of $\mathbf{\beta}=\{ \beta_c \}_{c=1}^C$:
$$
\text{Softmax}(\mathbf{x}_n,\beta_1,\dots,\beta_C)_c=\frac{\exp(\beta_c ^\top\mathbf{x}_n)}{\sum_{k=1}^{C}\exp(\beta_k^\top\mathbf{x}_n)  \, }, \text{ for } c\in\{ 1,\dots,C \}
$$
where $C$ denotes the number of classes.

> In practice, we only need $C − 1$ vectors of params (e.g., set $\beta_C$ = 0). This will ensure that your model implementation is identifiable!

**Generative process**
1. For each class $c\in\{ 1,\dots,C \}$
	1. Draw coefficients $\beta_c\sim \mathcal{N}(\beta_c|\mathbf{0},\lambda \mathbf{I})$
2. For each feature vector $\mathbf{x}_n$
	1. Draw class $y_n\sim \text{Categorical}(y_n|\text{Softmax}(\mathbf{x}_n,\beta_1,\dots,\beta_C))$

**Factorization**
$$
p(\mathbf{y}, \beta_1,\dots,\beta_C|\mathbf{X},\lambda)=\left( \prod_{c=1}^{C}p(\beta_c|\lambda)  \,  \right) \times \prod_{n=1}^{N} p(y_n|\mathbf{x}_n,\beta_1,\dots,\beta_C) \, 
$$
$$
\begin{aligned}
\underbrace{ p(\beta_1,\dots,\beta_C|\mathbf{y,X}, \lambda) }_{ \text{posterior} } &\propto \underbrace{ \left( \prod_{n=1}^{\infty} \mathcal{N}(\beta_c|\mathbf{0},\lambda \mathbf{I}) \,  \right) }_{ \text{prior} } \\
&\times \underbrace{ \prod_{n=1}^{N} \text{Categorical}(y_n|\text{Softmax}(\mathbf{x}_n,\beta_1,\dots,\beta_C)) }_{ \text{likelihood} } \,  
\end{aligned}
$$
## Hierarchical models
Assuming the data is grouped into $L$ distinct groups, where $l_n$ is used to denote the group that the $n^{th}$ observation belongs to, introduce shared global *hyper-prior* used to determine group-wise parameters $\beta_{c}^l$.

![[Pasted image 20260311144348.png|400]]

**Generative proces**:
1. For each class $c\in\{ 1,\dots,C \}$
	1. Draw global mean parameters $\mu_c\sim \mathcal{N}(\mathbf{\mu}_c|\mathbf{0},\lambda \mathbf{I})$
	2. Draw global variance parameter $\sigma_c\sim \mathcal{N}(\sigma_c|0,\tau)$
	3. For each level $l\in\{ 1,\dots,L \}$
		1. Draw coefficients $\beta'_c\sim \mathcal{N}(\beta'_c|\mathbf{\mu}_c,e^{\sigma_c}\mathbf{I})$
2. For each feature vector $\mathbf{x}_n$
	1. Draw class $y_n\sim \text{Categorical}(y_n|\text{Softmax}(\mathbf{x}_n,\beta ^{l_n}_1,\dots,\beta ^{l_n}_C))$

**Factorization**
$$
\begin{aligned}
p&(\mathbf{y}, \mathbf{B}^1,\dots,\mathbf{B}^L, \mathbf{\mu}_1,\dots,\mathbf{\mu}_C,\sigma_1,\dots,\sigma_C|\mathbf{X,I}) \\
&=\underbrace{ \left( \prod_{c=1}^{C}p(\mathbf{\mu}_c)p(\sigma_c)\prod_{l=1}^{L} p(\beta^l_c|\mathbf{\mu}_c,\sigma_c) \,   \,  \right) }_{ \text{hierarcical prior} } \times \prod_{n=1}^{N} p(y_n|\mathbf{x}_n,l_n,\mathbf{B}^1,\dots,\mathbf{B}^L) \, 
\end{aligned},
$$
where $\mathbf{B}^l=\{ \beta_1^\mathbf{l}\dots,\beta_c^l \}$.

### Variations of hierarchical models
There are many variants of this that we can consider
- A vector of variances $\sigma_c$ rather than a single variance $\sigma_c$ for all the features
- Different prior distributions on $\mathbf{\mu}_c$ , $\sigma_c$ and even $\beta^l_c$
- Hierarchical prior only on the biases (intercepts) rather than on all the $\beta_c$
- More levels, etc.

### Choice models
A subset of classification models, focusing on the behavioral processes leading to the observation of specific class labels.

#### Logit model
$$
P(y_n=i)=\frac{\exp(V_{ni})}{\sum_j\exp(V_{nj})}.
$$
- The logits for the different “classes” (choice alternatives) are defined by their respective utilities $V_{ni}$ rather than necessarily by $\beta_i^\top\mathbf{x}_n$.
- The utilities $V_{ni}=V(\mathbf{x}_{nj})$ can be arbitrary functions (typically linear parameters) of the alternative characteristics $\mathbf{x}_{nj}$.
- Mode choice example: $V_{\text{car}}=\beta_0+\beta_{\text{cost}}\cdot \text{cost}_\text{car}+\beta_{\text{traveltime}}\dots$


### Ordinal classification
Another type of classification problem concerns ordinal/ordered data: ratings (strongly disagree, disagree, neutral, agree, strongly agree), injury severity (none, light, severe, fatal), number of cars in household (0, 1, 2, more than 2), etc.

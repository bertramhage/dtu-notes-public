## PGM representation
PGMs represent a set of **conditional independence** relationships, eg.:
$$
c_n \perp a | b_n\quad \text{(}c_n\text{ is conditionally independent of }a \text{ given }b_n\text{),}
$$
factorised:
$$
p(a, \mathbf{b}, \mathbf{c}) = p(a)\prod_{n=1}^Np(b_n|a)p(c_n|b_n),
$$
where $\mathbf{b}=\{ b_n \}_{n=1}^N$ and $\mathbf{c}=\{ c_N \}_{n=1}^N$.

>
>![[Pasted image 20260211131421.png|300]]
>- Let **nodes** represent random variables
>	- Shaded nodes are **observed**
>	- Unshaded nodes are hidden or latent (**unobserved**)
>- Let **edges** express *probabilistic* relationships (not necessarily causal) between the variables
>- **Plates** indicate repetition (eg. for timesteps)

### Factorisation
Considering a joint distribution of **binary** random variables $\{ z_n \}_{n=1}^N$
$$
p(z_1,z_2,\dots,z_n)
$$
a naive approach (or a case of maximum dependence) of representing the full value set would include $2^N-1$ possible configurations.

Factorization breaks the joint distribution into a product of local conditional probability distributions
$$p(z_1, \dots, z_n) = \prod_{i=1}^{n} p(z_i \mid \text{parents}(z_i))$$
>[!example]- Example
>![[Pasted image 20260211134512.png|300]]
>$$
>\begin{aligned}
>p(z_1,z_2,z_3,z_4,z_5,z_6,z_7)&\\
>=&p(z_1)p(z_2)p(z_3)p(z_4|z_1,z_2,z_3)\\
>&p(x_5|z_1,z_3)p(x_6|z_4)p(x_7|z_4,x_5)
>\end{aligned}
>$$
>By factorising, we reduced the requirement to only $1 + 1 + 1 + 2^3 + 2^2 + 2 + 2^2=21$ parameters

>[!example]- Another factorization example
>![[Pasted image 20260211135754.png|300]]
>$$
>\begin{aligned}
>p(\boldsymbol{\theta}, \boldsymbol{\beta}, \mathbf{z}, \mathbf{w}) \\
=&\left(\prod_{k=1}^K p\left(\beta_k\right)\right)\times \\
& \prod_{d=1}^D p\left(\theta_d\right) \prod_{n=1}^{N_d} p\left(z_{d, n} \mid \theta_d\right) p\left(w_{d, n} \mid z_{d, n}, \boldsymbol{\beta}\right)
>\end{aligned}
>$$

## Bayes update
From Bayes rule follows
$$
p(\mathbf{z}|\mathbf{x}) = \frac{p(\mathbf{x}|\mathbf{z})p(\mathbf{z})}{p(\mathbf{x})}\quad \text{with }p(\mathbf{x})=\sum_zp(\mathbf{x}|\mathbf{z})p(\mathbf{z})
$$
**Intuition**: Posterior is the prior tilted toward hypotheses that make the observed data more likely.

> Bayesian updating is "prior odds $\times$ likelihood ratio"

>[!example]+ Tiny discrete example
>Hypotheses $z\in\{ z_1,z_2,z_3 \}$. We observe $x$.
>$$
>\begin{array}{lccc}
>\hline & z_1 & z_2 & z_3 \\
>\hline \text { Prior } p(z) & 0.60 & 0.30 & 0.10 \\
>\text { Likelihood } p(x \mid z) & 0.10 & 0.50 & 0.90 \\
>\hline \text { Unnorm. weight } p(x \mid z) p(z) & 0.06 & 0.15 & 0.09 \\
>\hline
>\end{array}
>$$
>**Step 1 (reweight)**: $w(z)=p(x|z)p(z)$
>**Step 2 (renormalize)**:
>$$
>p(x)=\sum_iw(z_i)=0.06 + 0.15 + 0.09 = 0.30,\quad p(z_i|x)=\frac{w(z_i)}{x}
>$$
>**Posterior**:
>$$
>p(z_1|x)=0.20,\quad p(z_2|x)=0.50,\quad p(z_3|x)=0.30
>$$

## Marginalisation in PGMs
For a set of latent variables $\{ z_n \}_{n=1}^N$ and observed variables $\{ x_m \}_{m=1}^M$ in order to calculate $p(z_i|\mathbf{x}_o)$, where $\mathbf{x}_o$ denotes observed variable that are dependent on $z_i$, we can marginalize
$$
p(z_i|\mathbf{x}_o)=\frac{p(z_i, \mathbf{x}_o)}{p(\mathbf{x}_o)}\propto \sum_{z_1}\sum_{z_2}\cdots\sum_{z_n \backslash z_i}\quad \sum_{x_1}\sum_{x_2}\cdots \sum_{x_m \backslash \mathbf{x}_o}p(\mathbf{z},\mathbf{x})  \,  \, 
$$
where $z_n \backslash z_i$ means "skipping" $z_i$ – and the same for $\mathbf{x}_o$.

If we have unobserved $x$ values, we likewise add it to the marginalisation (adding a sum for unobserved $x$).

## "Explaining away"
For a variable being dependent on two different other variables, observing one changes our belief about the other one.

![[Pasted image 20260211154312.png|200]]
![[Pasted image 20260211154326.png|200]]
**Example**: If the chance of John taking the car $p(b=1)$ is dependent on it raining $r=1$ and whether he has a time constraint $c=1$, if we observe $c=1$ the probability of $r=1$ drops, since there is another possible explanation for $b=1$.

### A simple algorithm for D-seperation
For any expression
$$
\text{"is } \mathbf{x} \text{ independent of } \mathbf{y} \text{ given } \mathbf{z}\text{", (} \mathbf{x} \perp \mathbf{y}|\mathbf{z})
$$
1. Draw the ancestral graph
	- It is the part of the original graph that has only the variable sets $\mathbf{x}, \mathbf{y}$ and $\mathbf{z}$, and all their ancestors among them
2. Moralise the graph by marrying the parents
	- For each pair of variables with a common child, draw an undirected edge (line) between them (if a variable has more than two parents, draw lines between every pair of parents)
3. Disorient the graph by replacing all edges for undirected ones
4. Delete the variables $\mathbf{z}$ (and any other observed variables not explicitly included in $\mathbf{z}$), and their edges

**Analysis of the result**
- If $\mathbf{x}$ and $\mathbf{y}$ are disconnected, then they are conditionally independent given $\mathbf{z}$!
- Being disconnected means that there is no possible path between $\mathbf{x}$ and $\mathbf{y}$ in the resulting graph
- Otherwise, they are not proven to be independent

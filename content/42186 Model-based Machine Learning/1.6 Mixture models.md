**Problem**:
- Sub-populations of data
- Data generated from combination/competition of multiple sources
- Number of sources usually discrete and finite

![[Pasted image 20260225154712.png|500]]
## Generative process of mixture models

1. Draw mixture components $\pi \sim \text{Dirichlet}(\alpha)$
2. For each mixture component (Gaussian) $k \in \{1, \ldots, K\}$
   3. Draw mean vector $\boldsymbol{\mu}_k \sim \mathcal{N}(0, \sigma_\mu I)$
   4. Draw covariance matrix $\boldsymbol{\Sigma}_k \sim \mathcal{W}^{-1}(\Psi, \nu)$
   
5. For $n = 1, 2, \ldots, N$
   6. Draw $z_n \sim \text{Categorical}(\pi)$, where $\pi$ is a vector $(1 \times K)$ with the probabilities of each class
   7. Generate $\mathbf{x}_n$, from the k-th Gaussian, $\mathbf{x}_n \sim \mathcal{N}(\boldsymbol{\mu}_{z_n}, \boldsymbol{\Sigma}_{z_n})$

**Factorization:**
$$
p(\pi) \left( \prod_{k=1}^{K} p(\mu_k)p(\Sigma_k) \right) \prod_{n=1}^{N} p(z_n|\pi)p(\mathbf{x}_n|\mu_{z_n}, \Sigma_{z_n})
$$
- $\mathbf{\pi}\sim \text{Dirichlet}(\alpha)$
- $\mathbf{\mu}_\mathbf{k}\sim \mathcal{N}(\mathbf{0}, \sigma_\mu \mathbf{I})$
- $\mathbf{\Sigma_k}\sim \mathcal{W}^{-1}(\mathbf{\Psi}, \mathcal{v})$, where $\mathcal{W}^{-1}$ denotes the Inverse Wishart distribution; typically $\mathcal{v}=$degrees of freedom (typically number of dimensions of $\mathbf{x}$), and $\Psi=\mathbf{I}$.

The factorization becomes
$$
\text{Dirichlet}(\mathbf{\pi|\alpha})\left( \prod_{k=1}^{K}\mathcal{N}(\mathbf{\mu_k}|\mathbf{0}, \sigma_\mu \mathbf{I})\mathcal{W}^{-1}(\mathbf{\Sigma_k|\Psi}, \mathcal{v})  \,  \right) \prod_{n=1}^{N} \pi_{z_n}\mathcal{N}(\mathbf{x|\mu_{z_n},\Sigma_{z_n}}) \, 
$$

For PGMs in the continuous domain we use **functions** (typically a well-known distribution, or combination hereof) parameterised by a set $\theta$.

**Example – Gaussian**
![[Pasted image 20260218104236.png|150]]
In this PGM we assume that observations $x_n$ follow a Gaussian distribution with parameters $\mu$ and $\sigma^{2}$.

Likelihood function:
$$
L(\mu,\sigma)=\prod_{i}^{N} \frac{1}{\sqrt{ 2\pi }\sigma}e^{\left( -\frac{(x_i-\mu)^{2}}{2\sigma^{2}} \right) } \, ,
$$
log version:
$$
LL(\mu,\sigma)=-\frac{N}{2}(\log(2\pi)+\log(\sigma^{2}))-\frac{1}{2\sigma^{2}}\sum_i(x_i-\mu)^{2}
$$

### Priors for parameters
We can assign **priors** to parameters.

Assume that for the Gaussian example above $\mu$ is unknown and follows a parametrised distribution with parameters $\theta$. If $\theta$ is itself normal $p(\mu, \mathbf{x})$ is normal too.

$$
\begin{aligned}
p(\mu,\mathbf{x}|\theta, \sigma)=&p(\mu|\theta)\prod_{n=1}^{N} p(x_n|\mu,\sigma) \, \\
p(\mu|\theta)=&\mathcal{N}(\mu|\alpha,\gamma) \\
LL(\mu,\alpha,\gamma,\sigma)=&-\frac{N}{2}(\log(2\pi)+\log(\sigma)) \\
&-\frac{1}{2\sigma^{2}}\sum_i(x_i-\mu)^{2} \\
-\frac{\log(2\pi)}{2}&-\frac{\log(\gamma^{2})}{2}-\frac{(\alpha-\mu)^{2}}{2\gamma^{2}}
\end{aligned} 
$$
## Conjugate priors

>[!info] Conjugate priors
>For many known distributions, there is a corresponding conjugate prior $P$ that preserves it form under multiplication. I.e. if we have a distribution $L$ and its conjugate prior $P_0$ we should have
>$$
>P_1=L\times P_0,
>$$
>where $P_1$ has the same form as $P_0$.

For example, starting with a Beta distribution and adding Bernoulli data, the result is still a Beta distribution.

**Online Learning:** For streaming data, update incrementally by treating current posterior as new prior — no need to recalculate from scratch.

### List of conjugate priors
| Likelihood                                     | Prior                  |
| ---------------------------------------------- | ---------------------- |
| Normal with known variance                     | Normal                 |
| Normal with known mean                         | Inverse Gamma          |
| Multivariate normal, known mean                | Inverse Wishart        |
| Multivariate normal, unknown mean and variance | Normal-inverse-Wishart |
| Exponential                                    | Gamma                  |
| Bernoulli                                      | Beta                   |
| Multinomial                                    | Dirichlet              |
| Poisson                                        | Gamma                  |

### Gaussian example revisited
For the above Gaussian example the posterior $p(\mu|\mathbf{x})=\mathcal{N}(\tilde{\alpha}, \tilde{\gamma})$ will be directly:
$$
\begin{aligned}
\tilde{\alpha}&=\frac{1}{\gamma ^{-2}+\frac{N}{\sigma^{2}}}\left( \frac{\alpha}{\gamma^{2}}+\frac{\sum_{i=1}^{N} x_i \, }{\sigma^{2}} \right)  \\
\tilde{\gamma}& = \sqrt{ \left( \gamma ^{-2}+\frac{N}{\sigma^{2}} \right) ^{-1} }
\end{aligned}
$$

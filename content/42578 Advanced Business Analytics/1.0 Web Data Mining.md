Combines data mining and machine learning techniques to extract valuable knowledge from web data.

**Used for eg.:**
- Customer segmentation
- Competitor analysis
- Trend and sentiment analysis

## Types of web mining
-  Web Content Mining
	- Extracting knowledge from the **contents** of web documents
- Web Usage Mining
	- Extracting patterns from the user interactions with web resources
- Web Structure Mining
	- Discovering patterns from the hyperlink structure


#### Channels
- APIs (eg. REST)
- HTML / page-level extractions (scraping)
- Pre-packaged web data (open data portals, statistical offices, etc.)

## APIs vs Web crawlers vs Pre-package datasets
|  | Pros | Cons |
| :--- | :--- | :--- |
| Third party APIs | - Convenient, easy to use <br> - Safe, won't be blocked <br> - Versatile (to some extent) | - Need to manage API keys <br> - Limit on access |
| Web crawlers / scrapers | - Very flexible. Theoretically, you can collect anything you find. | - Data structure can change <br> - May be blocked <br> - Terms & Conditions |
| Pre-packaged datasets | - Convenient, one download <br> - Safe, won't be blocked | - Inflexible <br> - Quickly outdated |

## LLMs
With prompt engineering we can also:
- Search the web for specific content
- Analyse a page source and extract tags
- Check legality / terms of a service
- Generate **synthetic data**. Good to stress test your models

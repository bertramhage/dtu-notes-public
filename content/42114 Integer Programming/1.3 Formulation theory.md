## Polyhedron and formulation

>[!info] Polyhedron
>Let $X$ be the set of feasible solutions for a MIP.
>
>A subset of $R^n$ described by a finite set of linear constraints $P=\left\{ x\in R^n: Ax\le b \right\}$ is a **polyhedron**
>
>For a MIP: A polyhedron $P\subset R^{n+p}$ is a **formulation** for a set $X\subset Z^n\times R^p$ if and only if $X=(Z^n\times R^p)\cap P$
>
>For a IP: A polyhedron $P\subset R^n$ is a **formulation** for a set $X\subset Z^n$ if and only if $X=Z^n \cap P$

>[!info] Convex Hull
>Given a set $X\subset R^n$ the convex hull of $X$, denoted conv($X$)  is defined as:
>$$
>conv(X)=\left\{ x: x=\sum_{i=1}^{t} \lambda_ix^i, \sum_{i=1}^{t} \lambda_i=1, \lambda\ge_0 \text{ for } i=1,\dots,t \text{ over all finite subsets }\left\{ x^1,x^2,\dots,x^t \right\} \text{ of }X \,  \,  \right\} 
>$$

Given a set $X\subset R^n$ and two formulations $P_1$ and $P_2$ for $X$, $P_1$ is a *better formulation* than $P_2$ if $P_1\subset P_2$.

## Projection
Compare formulations of different dimensions

>[!info] Projection definition
>Given a polyhedron $Q\subset R^n\times R^p$ the projection of $Q$ onto the subspace $R^n$, denoted $proj_xQ$ is defined as
>$$
>proj_xQ=\left\{ x\in R^n:(x,w)\in Q \text{ for some }w\in R^p \right\} 
>$$

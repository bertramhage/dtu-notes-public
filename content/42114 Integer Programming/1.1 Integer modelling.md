## Linear program

$$
max\left\{ cx|Ax\le b, x \ge 0 \right\} 
$$
where $A$ is an $m\times n$ matrix, $c$ is a vector of size $n$, $b$ a vector of size $m$ and $x$ is a vector of variables.

>If two variables are multiplied constraint is not linear.

### Mixed integer program

If some but not all variables are integer we have a (linear) mixed integer program (MIP)

$$
\begin{aligned}
max\quad cx\quad +\quad hy\\
st.\quad Ax\quad +\quad Gy\le b \\
& x \ge 0,\quad y\ge 0 \text{ and integer}
\end{aligned}
$$
### Integer program
If *all* variables are integer, we have an Integer (Linear) Program

$$
\begin{aligned}
 max\quad cx \\
s.t\quad Ax \le b \\
& x \ge 0 \text{ and integer}
\end{aligned}
$$

### Binary integer program
If all variables are not only integer but restricted to the values 0 or 1, we have a Binary Integer Program
$$
\begin{aligned}
max\quad cx \\
s.t.\quad Ax \le b \\
& x \in \left\{ 0,1 \right\}^n
\end{aligned}
$$

### Examples

>[!example]+ The 0-1 Knapsack Problem
>**Task:** Chose which items to bring to optimise "profit" without overfilling backpack.
>
>- What to decide:
>	- For each item, add it or not: $x_{i}\in\left\{ 0,1 \right\}$ for item $i$.
>- Objective: 
>	- Maximize profit, $max \sum_{i=1}^{n} c_i x_i \,$
>- Constraints:
>	- $\sum_{i=1}^{n} w_i x_i \le b \,$
>
>**Example in Julia**
>```Julia
>using JuMP, GLPK
>
>profit = [5, 3, 2, 7, 4]
>weight = [2, 8, 4, 2, 5]
>capacity = 10
>
>model = Model(GLPK.Optimizer)
>
>@variable(model, x[1:5], Bin)
>@objective(model, Max, sum(profit[i]*x[i] for i=1:5))
>@objective(model, Max, dot(profit,x)) # or using dot function
>@constraint(model, sum(weight[i]*x[i] for i=1:5) <= capacity)
>
>optimize!(model) # solve
>
println("Objective is: ", objective_value(model)) println("Solution is: ")
for i in 1:5 
>	print(value(x[i]), " ")
end
>```

## Innovative use of variables in IP
### Big-$M$ method
Consider a binary variable $x_t$ and a positive real/integer variable $y_t$
To model:
If $x_t=0$ then $y_t=0$, but if $x_t=1$ $y_t$ can be any positive (integer) value.
- Let $M$ be a **large** number, larger than we would ever assign to $y_t$
- Model what we want with $y_t \le Mx_t$.

### Functions with $N$ possible values
Given a total of $N$ constraints $f_i(x_1,x_2,\dots,x_n)\le d_i$, $k$ of them must be respected.

Use $y_i=1$ to indicate that constraint $i$ holds, and 0 otherwise, thus for $i=1,\dots N$:
$$
f_i(x_1,x_2,\dots,x_n)\le d_i + M(1-y_i)
$$
and
$$
\sum_{i=1}^{N} y_i \ge k \, .
$$

### Or-constraints
$$
\begin{aligned}
3x_1+2x_2 \le 18 + My \\
x_1+4x_2 \le 16 + M(1-y)
\end{aligned}
$$
where $y$ is a binary auxiliary variable, corresponds to one or the other constraint needs to holds true.

### Functions with $N$ possible solutions
$$
f(x_1,x_2,\dots, x_n)=d_1 \text{ or } d_2 \text{ or } \dots \text{ or } d_N
$$
is equivalent to 
$$
\begin{aligned}
f(x_1,x_2,\dots,x_n)=\sum_{i=1}^{N} d_iy_i \\
\sum_{i=1}^{N} y_i=1 \, 
\end{aligned}
$$

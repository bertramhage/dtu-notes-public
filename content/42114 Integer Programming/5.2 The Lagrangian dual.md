## The subgradient method (solving the Dual)

Subgradient (Search direction):
$$
\gamma(u^k) = 
\begin{cases}
Dx^k - d & (\text{for } \leq \text{ or } = \text{ constraints})\\
d - Dx^k & (\text{for } \geq \text{ constraints})
\end{cases}
$$
Update rule:
$$
u^{k+1}=\max\left\{ 0, u^k+\mu_k\gamma(u^k) \right\} 
$$
where $\mu_k$ denotes the step length.
- If constraint is violated, $\gamma>0$,  $u$ **increases**
- If constraint is satisfied, $\gamma$ is non-positive, so $u$ **decreases**

> **Note**: For equality constraints the multipliers are unrestricted in sign (free), so the $\max\{0, \cdot\}$ projection is removed from the update rule.

### Choosing step size
- Constant step size
$$
\mu_k = \mu (\mu > 0)
$$
- Constant step length
$$
\mu_k = \frac{\alpha}{\mid\mid \gamma(u^k)\mid\mid_2}\quad (\alpha>0)
$$
- Diminishing step sizes (guarranteed convergence)
	If
	-  $\sum_{k=1}^{\infty} (\mu^k)^2<\infty \,$
	- $\sum_{k=1}^{\infty} \mu^k \,=\infty$
	convergence is guaranteed.
	*Example*: $\mu_k=\frac{1}{k}$

- Geometric decrease
$$
\mu_k = \mu_1 \rho^k\quad (\text{with }0<\rho<1, \mu_1>0)
$$
- Polyak choice
$$
\mu_k=\epsilon_k \frac{z(u^k)-\bar{w}}{\mid\mid\gamma(u^k)\mid\mid_2^2}\quad (0<\epsilon_k\le2)
$$
	where $\bar{w}$ is an upper bound on $W_{LD}$.

## Primal solutions

- **Lagrangian Heuristics** is used to adjust the infeasible dual solution $x^k$ into a feasible solution providing an upper bound $\bar{z}$.
- **Variable fixing**: if $\underline{z}=z_{LD} \text{ and } \bar{z}$ is the best *feasible* solution, a variable $x_k$ with coefficient $C_k$ can be fixed:
$$x_k=0 \text{ if } \underline{z} + C_k > \bar{z} \text{ (assuming } C_k>0)$$

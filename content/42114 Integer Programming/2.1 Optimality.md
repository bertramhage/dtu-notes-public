Basic solution approach to any integer program or combinatorial optimisation problem:
$$
Z = \max\left\{ c(x): x \in X \subseteq Z^n \right\} 
$$
- Find lower bound $\underline{z}$ such that $\underline{z}\le z$
- Find upper bound $\bar{z}$ such that $\bar{z}\ge z$

- **Primal bounds**: (lower bound for a $max$ problem). Every feasible solution $x \in X$ is a lower bound.
- **Dual bounds**: (upper bound for a $max$ problem). Most important approach is by relaxation, that is, replace the original problem by a simpler optimisation problem whose value is at least as large as $z$.

## Dual bounds
Relax the challenge by introducing a simpler optimisation problem whos optimal value is at least as large (small) as the original. Either by
1. Enlarge the set of feasible solutions so that one optimises over a larger set, or
2. Replace the max (min) obj function by a function that has the same or a larger (smaller) value on all the original feasible solutions.

## Relaxation

>[!info] Relaxation
>A problem $(RP) Z^{RP}=\max\left\{ f(x):x \in T\subseteq \mathbb{R}^n \right\}$ is a *relaxation* of $(IP) Z=\max\left\{ c(x): x \in X \subseteq \mathbb{R}^n \right\}$ if
>1. $X\subseteq T,$ and
>2. $f(x)\ge c(x) \forall x\in X$.
>
>**Proposition**
>If $RP$ is a relxation of $IP$, $Z^{RP}\ge Z$.

### Linear programming relaxations
Replace with a problem that allows positive real values.

>[!info] Definition
>For the integer program $Z=\max\left\{ cx : x \in P \cap \mathbb{Z}^n \right\}$ with formulation $P=\left\{ x \in \mathbb{R}_+^n : Ax\le b \right\}$, the *linear programming relaxation* is the linear program
>$$
>Z^{LP}=\max\left\{ cx : c \in P \right\} 
>$$

### Combinatorial relaxation
Replace with a related, but easier, combinatorial optimisation problem.

>[!example]+ Traveling salesman problem
>The TSP problem with digraph $D=(V,A)$ and arc weights $c_{ij} \text{ for } (i,j)\in A$ the tours are precisely the assignments containing no subtours. Thus,
>$$
>\begin{aligned}
>&Z^{TSP} = \min_{T\subseteq A} \left\{ \sum_{(i,j)\in T}c_{ij} : T \text{ forms a tour} \right\} \ge  \\
>&Z^{ASS} = \min_{T\subseteq A}\left\{ \sum_{(i,j)\in T}c_{ij}: T \text{ forms an assignment} \right\} 
\end{aligned}
>$$

### Lagrangian relaxation
Move its "complicating constraints" into the objective function, penalising or rewarding their violation with Lagrange multipliers.

Given an IP problem:
$Z=\max\left\{ cx: Ax\le b, x \in X \right\}$

Relax it by:
Let $Z(u)=\max\left\{ cx + u(b-Ax): x \in X \right\}$

Then 
$Z(u)\ge Z$ for all $u\ge_0$.

## Duality
Duality provides a standard way to obtain upper bounds.

>[!info] Weak and strong duality
>**Weak duality**
>The two problems
$z = \max\left\{ c(x): x \in X \right\}$ and $w=\min\left\{ w(u) : u \in U \right\}$
form a *weak-dual pair* if $c(x)\le w(u) \forall x \in X, \forall u \in U$
>
>**Strong duality**
>if $z=w$, that is, there exists $x^* \in X$ and $u^* \in U$ such that $c(x^*)=w(u^*)$ they form a *strong-dual pair*.
>

Linear programming relaxations immediately lead to a weak duality
- The integer program $z=\max\left\{ c(x) : Ax \le b, x \in \mathbb{Z}_+^n \right\}$ and the linear program $w^{LP}=\min\left\{ ub : uA \ge c, u \in \mathbb{R}_+^m \right\}$ form a weak dual pair
- Suppose that IP and D are a weak dual pair
	- If D is unbounded, IP is infeasible
	- If $x^* \in X$, $u^* \in U$ satisfy $c(x^*)=w(u^*)$ then $x^*$ is optimal for IP and $u^*$ is optimal for D.

## Matchings and coverings
**Matching**: Given a graph, a *matching* is a subgraph with the property that no two edges are incident with the same node
**Covering**: Given a graph, a *cover* is a subset of nodes such that at least one endpoint for all edges belongs to the cover

## Greedy heuristic
A *heuristic* is a method for finding a feasible but not necessarily optimal solution to a problem
A *greedy heuristic* iteratively generates a feasible solution by making a sequence of choices, each time the choice that brings the "best" immediate reward is taken.

## Traveling salesman problem
Undirected weighted graph: cities are vertices, edges are connections between cities, the weight of an edge gives the distance. Can be symmetric or asymmetric.

![[Pasted image 20250909152502.png|400]]
- $x_{ij}\in \left\{ 0,1 \right\}$ binary variable denoting a trip between city $i$ and $j$.
- Objective function: $\sum_{i=1}^{n} \sum_{j=1}^{n} c_{ij}x_{ij} \, \,$, where $c_{ij}$ is the distance.
- Contraints
	- "For every city $i$ we enter the city from exactly one other city and exit it towards exactly one other city"
		- $\sum_{i=1}^{n} x_{ij}=1 \text{ for each } j=1,2,\dots n \,$
		- $\sum_{j=1}^{n} x_{ij}=1 \text{ for each } i=1,2,\dots n \,$
	- "If too many edges with both endpoints in a subset $S$ are chosen a subtour is made"
		- $\sum_{i\in S}\sum_{j\in S}x_{ij}\le |S|-1 \text{ for } S \subset N, S\neq \emptyset$

### As sequence numbers
Introduce integer variable $s_i$, $i=1,2,\dots,n$ indicating the sequence in which the cities are visited.
- $s_1=1$
- $x_{ij}=1\implies s_j=s_i+1$ sufficient to write $x_{ij}=1\implies s_j\ge s_i+1$
- $s_j\ge s_i+1-M(1-x_{ij})$ (MIP constraint)
- For all $i,j$ where $j\neq 1$

## Uncapacitated facility location (UFL)
Given a set of depots $N=\left\{ 1,2,\dots,n \right\}$
and a set $M=\left\{ 1,2,\dots,m \right\}$ of clients,
suppose there is a fixed cost $f_j$ assicoated with the use of depot $j$,
and a transportation cost $c_{ij}$ if all the order of the client $i$ is delivered from the depot $j$.

#### Formulation
- $x_j\in\left\{ 0,1 \right\}$ denoting if depot $j$ is open
- $y_{ij}$ is the fraction of the demand client $i$ gets from depot $j$.

- Depot opening cost $\sum_{j\in N}f_jx_j$
- Transportation cost $\sum_{i\in M}\sum_{j\in N}c_{ij}y_{ij}$
- In total: minimize depot opening and transportation cost:
	- min  $\sum_{j\in N}f_jx_j + \sum_{i\in M}\sum_{j\in N}c_{ij}y_{ij}$

**Contraints**
- Satisfaction of client demand
	- $\sum_{j\in N}y_{ij}=1 \text{ for } i\in M$
- We can only supply from a depot if it is open
	- $\sum_{i\in M}y_{ij}\le mx_j \text{ for } j\in N$

**In total:**
$\begin{array}{rr}\min \sum_{i \in M} \sum_{j \in N} c_{i j} y_{i j}+\sum_{j \in N} f_j x_j & \\ \sum_{j \in N} y_{i j} & =1 \\ \sum_{i \in M} y_{i j} \leq m x_j & \text { for } i \in M \\ 0 \leq y_{i j} \leq 1 & \text { for } j \in N \\ x_j \in\{0,1\} & \text { for } i \in M, j \in N \\ & \text { for } j \in N\end{array}$

## Bias:
- Systematic errors that differ between groups
- In order to detect bias we need to access the true labels, often by finding a reliable *proxy*

>**Notation**: Let a model $f(X)$ produce a score $R$ and a threshold function $\theta(R)$ produce a prediction $\hat{Y}\in\left\{ 0,1 \right\}$. Let $Y$ be the true label and $A$ be a sensitive variable.
## Independence
Equalizing the acceptance rate $\mathbb{P}\left\{ \hat{Y}=1 \right\}$.

>[!info] Definition
>The model $R$ satisfy *independence* if $R\bot A$.
>$$
>\mathbb{P}\left\{ \hat{Y}=1|A=a \right\} =\mathbb{P}\left\{ \hat{Y}=1|A=b \right\} 
>$$


## Separation (equalised odds)
Equalizing *true positive rate* and *false positive rate* $\Leftrightarrow$
Equalizing *false negative rate* and *true negative rate*.

>[!info] Definition
>The model $R$ satisfies separation if $R\bot A|Y$.
>$$
>\mathbb{P}\left\{ \hat{Y}=1|Y=1, A=a \right\}=\mathbb{P}\left\{ \hat{Y}=1|Y=1, A=b \right\}  
>$$
>$$
>\mathbb{P}\left\{ \hat{Y}=1|Y=0, A=a \right\}=\mathbb{P}\left\{ \hat{Y}=1|Y=0, A=b \right\}  
>$$
>**Equal opportunity** (less strict):
>Equal true positive rate only (i.e. recall):
>$$
>\mathbb{P}\left\{ \hat{Y}=1|Y=1, A=a \right\}=\mathbb{P}\left\{ \hat{Y}=1|Y=1, A=b \right\}  
>$$

## Sufficiency
All information on group is contained in the score.

>[!info] Definition
>The model $R$ satisfies sufficiency if $Y\bot A|R$.
>$$
>\mathbb{P}\left\{ Y=1|R=r, A=a \right\} = \mathbb{P}\left\{ Y=1|R=r, A=b \right\} 
>$$
>For binary prediction:
>$$
>\mathbb{P}\left\{ Y=1|\hat{Y}=1, A=a \right\} = \mathbb{P}\left\{ Y=1|\hat{Y}=1, A=b \right\} 
>$$
>$$
>\mathbb{P}\left\{ Y=1|\hat{Y}=0, A=a \right\} = \mathbb{P}\left\{ Y=1|\hat{Y}=0, A=b \right\} 
>$$

Calibration by group $\implies$ sufficiency.

> If a model $R$ satisfies sufficiency, then there exists a calibrating function $l : [0, 1] → [0, 1]$ so that $l(R)$ satisfies calibration by group.

## Exclusivity

1. Assuming $A\not\perp Y$:
	- Independence and sufficiency are mutually exclusive
2. Assuming $Y\in\{ 0,1 \}, A\not\perp Y$, $R\not\perp Y$:
	- Independence and separation are mutually exclusive
3. Assuming all events in $(A,R,Y) \text{ have } \mathbb{P} > 0, A \perp Y$
	- Sufficiency and separation are mutually exclusive

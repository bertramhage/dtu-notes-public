## Assumptions

### Modelling

**Parametrisation**
- Picking a model (ie. GMM, graphical model, NN, etc.)

**Selection problem**
- Occam's razor: models should be made big beyond recessity
- Falsifiability: to test and falsify (based on Occam's razor)
- Model capacity (ie. number of parameters, layers)
- Physical constraints (for architecture, etc)
- "Innate" knowledge, eg. similarity to brain neural networks

>[!info] VC-dimension
>- Notion of model capacity/complexity
>- Shatter: Class $H$ can classify all subsets of set $A$
>- VC-dimension of $H$ in $2D$ is $x=|A|$ if exists a set $A$ that can be shattered by $H$ and if not exist any set with size $x+1$ to be shattered by $H$.

**Structural risk minimisation**
- Bias vs. variance trade of
- We assume we can use regularisation (eg. L1, L2)

**(Stochastic) optimisation: convergence bias**
- Eg. double descent
- SDG has innate biases, preferring specific learning rate, data size, etc.

**Structured Prediction**
- Algorithmic generalisation of the models to generate structured output
- Structure is often given a-prior by expert design

**Likelihoodism**
- Likelihoodists do not assume a (prior) distribution on the model – model is fixed
- Eg. "we pick ResNET18 for modelling", as if this is set in stone

**Consequentialism: Orthodox Likelihoodists**
- Consider data only as evidence and do not use it as the basis of statistical inference

### Statistical learning

**Risk minimisation**
- Minimises negative log-likelihood

**Empirical risk minimisation**
- Finite set of samples representative of the unknown distribution
- Most often assuming
	- Weak law of large numbers
	- Convergence in probability
	- Central limit theorem

**Non-parametric learning**
- Eg. Kernel machines (Gaussian SVM), $k$-Nearest neighbours, ...
- Popular in practice: simple and explainable
- Need good amount of data

**Probably Approximately Correct (PAC)**
$$
error(h)=P_x(h(x)\neq c(x))=\sum_{x \in h \Delta c} p(x)
$$
$C$: set fo all possible concepts $c \subseteq \left\{ 0,1 \right\}^n$, with $n>1$
$H$: set of all possible hypotheses $h \subseteq \left\{ 0,1 \right\}^n$, with $n>1$
$\delta<1, \epsilon>0$

The concept class $C$ is PAC learnable by the hypothesis space $H$ if there exist training algorithm $A$ that with probability $1-\delta$ returns a hypothesis $h$ st. $error(h)< \epsilon$, i.e. $A$ is a PAC learning algorithm for $C$.

- Limitations
	- Assuming hypothesis class is VC-finite
	- Cannot address NP-complete problems
	- Worst-case emphasis

**Statistical inference**
- Deterministic
	- Exact: often infeasible on arbitrary data
	- Laplace approximations
	- Variational: Remap to tractable distributions (eg. Gaussians)

- Stochastic
	- Sampling-based: Eg. MCMC
	- Iterative: updating the estimate based on samples
	- Stochastic Variational: tractable distributions of random batches

### Statistics

**Bayes rule**
Hypothesis $H$, and evidence $E$:
$$p(H|E)=\frac{p(E|H)p(H)}{p(E)}$$

If $p(E|H)=p(E)\implies p(H|E)=p(H)$, ie. we cannot learn from evidence.


**Memoryless property**
- Markov property: Process that is memoryless, future evolution is independent of history and only depends on current state
- Markov process is time reversible

### Probability theory

**Kolmogorov axioms**
- $P$ between 0 and 1, $P \text{ and } \neg P$ add to one

**Probabilities**
- Derivatives of axioms (join distributions, independence, etc.)

**Conditional probability**
- $P(X|Y)$ not defined if $P(y)=0$ (Danish king is bald, pre 2024)

**Conditional independence**
- We have enough evidence to separate two events
- Leads to other strong assumptions, eg. independent sampling

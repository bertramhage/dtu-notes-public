A saliency map is a heatmap in the image plane that aims to emphasize those regions of the image that were the most important – or *salient* – for the made prediction
![[Pasted image 20251023081452.png|300]]

For a function $f:\mathbb{R}^d\to \mathbb{R}$ the gradient
$$
\nabla_xf=\left( \frac{\partial f}{\partial x_1},\dots, \frac{\partial f}{\partial x_d} \right) 
$$
at $x_0\in R^d$ is a vector in $\mathbb{R}^d$ pointing in the direction of maximal slope.

For an image: $\nabla_xf \in\mathbb{R}^{H\times W}$.

## Vanilla saliency maps: Gradients
The vanilla saliency map is simple the gradient
$$
M_c=\nabla_xf_I(\theta,x)
$$
of the (for binary the correct) $I^{th}$ prediction of the network at $x$.

## SmoothGrad
Vanilla saliency maps tends to be noisy.

SmoothGrad applies Gaussian smoothing in image space via stochastic approximation:
$$
\hat{M}_c(x)=\frac{1}{n} \sum_n M_c(x+\mathcal{N}(0,\sigma^{2}))
$$
where $\sigma$ is the standard deviation of the Gaussian noise (hyperparameter), and $M_c$ is the vanilla saliency map of the image $x$.

![[Pasted image 20251023082630.png|400]]
## Integrated Gradients
Picks an "anchor point": $x'$, and like SmoothGrad samples images, but sampling from the interpolation between the specific sample $x_i$ and the anchor point $x_i'$:
$$
\text{IntegratedGrads}_i(x)::=(x_i-x'_i)\times \int_{\alpha=0}^{1} \frac{\partial f(x'+\alpha \times(x-x'))}{\partial x_i} \, d\alpha 
$$
## Class Activation Mapping (CAM)
Design CNN to have a global average pooling layer between last feature channels and final prediction layer mapping the feature channels to single values $w_1,\dots,w_n$:
![[Pasted image 20251023083323.png|450]]
Saliency maps are now the last feature channels weighted by values $w_{1},\dots,w_n$ upsampled.

## GradCAM
Further working of CAM, relaxing the need for a final global average pooling.

Activation mapping weight computed via gradients:
$$
w_k^c=\text{mean}(\nabla_{A^k}f_c(x))
$$
where $f_I(x)$ is the (before softmax) prediciton of the label $c$ for the input image $x$, $A^k$ is the features of the $k^{th}$ penultimate channel.

Saliency map (ReLU turns off negative contributions):
$$
M_c(x)=\text{ReLU}\left( \sum_k w_k^c A^k \right) 
$$

## Other saliency techniques

**Saliency via attention**:
The attention layer from attention modules (eg. from transformers) can also be visualized as a saliency map, thus leveraging an *intrinsic* importance and not post-hoc.

**LIME - Local Interpretable Model-Agnostic Explanation**:
LIME is a model-agnostic, post-hoc explanation technique that generates local, interpretable explanations for individual predictions by perturbing the input, observing how the black-box model's outputs change, and then fitting a simple, interpretable surrogate model (like linear regression) to approximate the model's decision boundary specifically for that instance.

**Layer-wise relevance propagation**:
Layer-wise Relevance Propagation (LRP) is a model-specific, backpropagation-based technique that computes a saliency map by redistributing a model's output prediction backward through its layers using a set of conservation rules, ensuring that the total "relevance" assigned to the input features equals the prediction score for a specific class.

**SHAP**
SHAP (SHapley Additive exPlanations) is a unified, game theory-based framework that explains individual predictions by computing the marginal contribution of each feature to the model's output, ensuring properties like local accuracy and consistency by approximating Shapley values from cooperative game theory.


>[!danger] Warning when interpreting saliency maps
>Saliency maps can sometimes hide wide regions that all together has a high contribution towards a prediction, but spread over a large sparse area. Common examples include backgrounds.

## Adversarial attacks
For an image $x\in \mathbb{R}^{H \times W}$ , classifier $f:\mathbb{R}^{H \times W}\to \left\{ 0,\dots,L \right\}$, and a target class label $I$, an adversarial attack on the image $x$ towards the class $I$ seeks to find the minimum image noise $r\in\mathbb{R}^{H \times W}$ such that
$$
\min \mid\mid r\mid\mid^{2} \text{ while }\quad  \begin{aligned}
&f(x+r)=I \\
&x+r \in [0,1]^{H \times W}
\end{aligned}
$$

**Fast gradient sign method for adversarial attacks**:
Obtains adversarial examples via noise 
$$
r=\epsilon \text{sign}(\nabla_x \mathcal{L}(\theta,x,y))
$$
for loss $\mathcal{L}$, image $x$, correct label $y$, model parameters $\theta$.

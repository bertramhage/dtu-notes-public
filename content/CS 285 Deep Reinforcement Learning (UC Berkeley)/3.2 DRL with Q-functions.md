## Double $Q$-learning
Regular $Q$-learning suffers from overestimation from the $Q$-value due to the combination of the $\max_{\mathbf{a}'}$ operation and noise in the untrained $Q$ function. 

Double $Q$-learning combats this by **de-correlating** the action selection from the action evaluation:
- **Action Selection:** Use the current/live network $Q_\phi$ to find the best action.
- **Action Evaluation:** Use the target network $Q_{\phi'}$ to evaluate that specific action.

## Multi-step ($N$-step) returns
Early in training, the Q-function is random/poor, meaning the target values are mostly useless noise. During this phase, the primary learning signal comes entirely from the single-step reward $r$.

We  incorporate multiple steps of real reward before bootstrapping with the $Q$-value, learning to lower bias, but higher variance.
$$
Y_{n\text{-step}} = \sum_{t'=t}^{t+n-1} \gamma^{t'-t} r_{t'} + \gamma^n \max_{a'} Q_{\phi'}(s_{t+n}, a')
$$
### Off-Policy Problem with N-Step Returns
Standard 1-step Q-learning is strictly off-policy. However, N-step returns are only technically valid for on-policy data.

**Solutions:**
1. **Ignore it:** Often works surprisingly well in practice.
2. **Dynamic Trace Cutting:** Dynamically truncate $N$ to the point where the buffer's actions diverge from your current deterministic greedy policy.
3. **Importance Sampling:** Construct a stochastic policy and weight the $N$-step returns using importance sampling.

## $Q$-learning with Continuous Actions
The $\max_{\mathbf{a}}$ operation is computationally difficult when the action space is continuous.

**Solutions:**
1. **Stochastic optimization:** Approximate the max by evaluating a discretely sampled set of random actions, or use iterative refinement methods like the Cross-Entropy Method (CEM) or CMA-ES.
2. **Easily optimizable function class:** Restrict the Q-network architecture so it is quadratic in the action space (e.g., Normalized Advantage Function - NAF). This guarantees a closed-form analytic maximum.
3. **Learn an approximate maximizer:** Train a separate deterministic policy network $\mu_\theta(\mathbf{s}) \approx \arg\max_{\mathbf{a}} Q_\phi(\mathbf{s}, \mathbf{a})$ to output the best action.
    - Update $\theta$ using the chain rule to push gradients through the Q-function: $\frac{dQ_\phi}{d\theta}=\frac{d\mathbf{a}}{d\theta} \frac{dQ\phi}{d\mathbf{a}}$
    - The target calculation becomes: $Y = r + \gamma Q_{\phi'}(\mathbf{s}', \mu_{\theta'}(\mathbf{s}'))\approx r_j+\gamma Q_\phi(\mathbf{s}'_j,\operatorname*{arg\,max}_\mathbf{a'}Q_\phi(\mathbf{s}'_j,\mathbf{a}'_j))$

## Practical Tips for $Q$-Learning

- **Stability:** $Q$-learning takes some care to stabilize. Debug and tune hyperparameters on simple, reliable environments before moving to complex tasks.
- **Replay buffers:** Using large buffers (e.g., ~1 million transitions) improves stability.
- **Exploration schedule:** Start with high exploration (large $\epsilon$) because early $Q$-values are bad. Decay $\epsilon$ gradually as the network learns.
- **Gradient clipping & Huber Loss:** Highly negative actions can produce massive Bellman errors, leading to large gradients. Use Huber loss or gradient clipping instead of standard MSE to mitigate this.
- **Optimization:** Use adaptive optimizers like Adam and schedule learning rates.
- **Seeds:** Run multiple random seeds because performance variance between runs can be large.

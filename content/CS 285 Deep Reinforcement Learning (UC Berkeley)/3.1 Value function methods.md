Having learned the value function we simply choose the best action from $\mathbf{s}_t$ regardless of $\pi$.
$$
\operatorname*{arg\,max}_{\mathbf{a}_t}A^\pi(\mathbf{s}_t,\mathbf{a}_t)
$$
$\pi$ is implicitly defined as
$$
\pi'(\mathbf{a}_t|\mathbf{s}_t)=\begin{cases}
1 \text{ if } \mathbf{a}_t=\operatorname*{arg\,max}_{\mathbf{a}_t}A^\pi(\mathbf{s}_t,\mathbf{a}_t) \\
0 \text{ otherwise}
\end{cases}
$$

## Policy iteration algorithm

![[Pasted image 20260223111132.png|250]]
Assume known $p(\mathbf{s'|s,a})$ for small and discrete $\mathbf{s}$ and $\mathbf{a}$.

For a finite state and action space we might store $V^\pi(\mathbf{s})$ in a table where $\mathcal{T}$ is a dim($\mathbf{s}$) $\times$ dim($\mathbf{s}$) $\times$ dim($\mathbf{a}$) tensor

Bootstrapped update:
$$
V^\pi(\mathbf{s})=\mathbf{E}_{\mathbf{a}\sim \pi(\mathbf{a|s})}\left[ r(\mathbf{s,a})+\gamma \mathbf{E}_{\mathbf{s'}\sim p(\mathbf{s'|s,a})}[V^\pi(\mathbf{s'})] \right] 
$$
with policy evaluation
$$
V^\pi(\mathbf{s})\leftarrow r(\mathbf{s}, \pi(\mathbf{s}))+\gamma \mathbf{E}_{\mathbf{s'}\sim p(\mathbf{s'|s},\pi(\mathbf{s}))}[V^\pi(\mathbf{s'})]
$$
### Simpler: Value iteration algorithm
$\operatorname*{arg\,max}_{\mathbf{a}}Q(\mathbf{s,a})\to \text{policy}$

## Fitted value iteration
Represent $V(\mathbf{s})$ as something else than a table $\to$ neural net $V:\mathcal{S}\to \mathbb{R}$

$\mathcal{L}(\phi)= \frac{1}{2}\mid\mid V_\phi(\mathbf{s})-\max_\mathbf{a}Q^\pi(\mathbf{s,a})\mid\mid^{2}$

![[Pasted image 20260223112647.png|350]]
### Fitted $Q$-iteration
Problem: We rarely know the transition dynamics of the environment.

Solution: Instead train a neural network to learn $Q(\mathbf{s}, \mathbf{a})$. Because the $Q$-function takes the state *and* the action as inputs, we don't need to simulate what happens if we take different actions.

This satisfy being a model-free and off-policy algorithm.

## $Q$-learning
Take exactly one action, observe the transition, calculate one target value, and take one gradient descent step.

![[Pasted image 20260223114011.png|400]]

### Exploration rules
**Greedy policy**:
$$
\pi(\mathbf{a}_t|\mathbf{s}_t)=\begin{cases}
1 \text{ if } \mathbf{a}_t=\operatorname*{arg\,max}_{\mathbf{a}_t}Q_{\phi}(\mathbf{s}_t,\mathbf{a}_t) \\
0 \text{ otherwise}
\end{cases}
$$
**$\epsilon$-greedy**:
$$
\pi(\mathbf{a}_t|\mathbf{s}_t)=\begin{cases}
1-\epsilon \text{ if }\mathbf{a}_t=\operatorname*{arg\,max}_{\mathbf{a}_t}Q_{\phi}(\mathbf{s}_t, \mathbf{a}_t) \\
\epsilon/(|\mathcal{A}|-1) \text{ otherwise}
\end{cases}
$$
**Boltzmann exploration**
$$
\pi(\mathbf{a}_t|\mathbf{s}_t)\propto \exp(Q_\phi(\mathbf{s}_t, \mathbf{a}_t))
$$

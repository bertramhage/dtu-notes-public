## Non-LP bounding
To obtain a bounding function
- **Leave out some constraints** keeping the objective function such that we maximize (minimize) over a larger solution space
- **Change the objective function** $f$ to $g$ such that
	- $g\ge f \forall x \in S$ for maximization
	- $g\le f  \forall x \in S$ for minimization

## Branching
Not trivial which strategy to choose:
- Branch on most **fractional** variable
- Branch on least **fractional** variable
- "Estimate the cost of forcing $x_j$ to become integer" 

>[!example]-  Build-in branching strategies in CPLEX
>| **Rule**         | **Description** |
>|------------------|-----------------|
>| **MININFEAS**    | The minimum infeasibility rule chooses the variable with the value closest to an integer but still fractional. The minimum infeasibility rule may lead more quickly to a first integer feasible solution, but is usually slower overall to reach the optimal integer solution. |
>| **MAXINFEAS**    | The maximum infeasibility rule chooses the variable with the value furthest from an integer. The maximum infeasibility rule forces larger changes earlier in the tree. |
>| **DEFAULT**      | ILOG CPLEX decides each branch direction. |
>| **PSEUDO**       | Use pseudo costs, which derives an estimate about the effect of each proposed branch from duality information. |
>| **STRONG**       | Strong branching causes variable selection based on partially solving a number of subproblems with tentative branches to see which branch is the most promising. This strategy can be effective on large, difficult MIP problems. |
>| **PSEUDOREDUCED**| Use pseudo reduced costs, which is a computationally less intensive form of pseudo costs. |

## Example - Symmetric TSP
$$
\begin{align}
\min & \sum_{(i,j)\in E, i<j}d_{ij}x_{ij}& \\
s.t.&\sum_jx_{ij}=2&i \in \left\{ 1,2,\dots,n \right\}  \\
&\sum_{i,j\in S}x_{ij}\le |S|-1&\emptyset \subset S \subset V \\
&x_{ij} \in \left\{ 0,1 \right\} &(i,j) \in E  \, 
\end{align}
$$
where $x_{ij}=x_{ji}$.

>[!info] Minimum spanning tree
>Let $G=(V,E)$ be a graph, then
>- A tree $T$ is a connected subgraph with no cycles of $G$
>- Spanning: All vertices are in the $T$
>
>**The minimum spanning tree problem**
>Given costs $w_e$ for each arc $e$ the minimum spanning tree problem consists of finding a spanning tree of minimum cost.
>
>**Kruskals Algorithm**
>1 $F \leftarrow \emptyset$;
>2 sort edges by nondecreasing cost (denote the list $\mathcal{L}$);
>3 **for** each $(u,v) \in \mathcal{L}$ **do**
>4 $\quad$ **if** a path from $u$ to $v$ in $F$ does not exist **then**
>5 $\quad\quad$ $F \leftarrow F \cup \{(u,v)\}$;
>6 $\quad$ **end**
>7 **end**
>The algorithm can terminate as soon as $n − 1$ edges have been included in $F$ (where n is the number of nodes).

### $1$-tree bound
For finding a lower bound for the STSP
1. Identify a special vertex $1$ (can be any vertex of the graph)
2. Remove $1$ and all incident edges from $G$
3. For the remaining graph determine the minimum spanning tree $T$
4. Add two lightest edges $e_1$, $e_2$ incident with $1$ to $T$ producing $T_1$ (called a $1$-tree)

The set of Hamiltonian tours is a subset of $1$-trees of $G$.

### Strengthen the bound
Define $\pi_i$ as the degree of vertex $i$ minus 2
For each edge $(i,j) \in E$ we transform the cost to $d'_{ij}=d_{ij}+\pi_i+\pi_j$
For a Hamilton cycle the cost is unchanged
$$
\sum_{(i,j)\in H}d'_{ij}=\sum_{(i,j) \in H}d_{ij}+\sum_{i \in V}\pi_i+\sum_{j\in V}\pi_j=\sum_{(i,j) \in H}d_{ij}
$$
### 4 steps of a B&B iteration
For the current node, do the following:
1. **Generate bound** the cost of $T_1$ is less than or equal to the cost of any Hamiltonian tour
2. **Can we prune?** In the case $T_1$ is a Hamilton tour we have foudn the optimal solution and can prune by bounding
3. **If not, branch**
4. Select next node, repeat

### How to branch
- Observe that in the case of $1$-tree is not a Hamilton tour, at least one vertex has degree 3 or more
- So choose a vertex $v$ with degree 3 or more.
- For each edge $(u,v)$ generate a subproblem where $(u,v)$ is excluded from the set of edges.

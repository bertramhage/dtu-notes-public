**Invariance and equivalence**
In images we want translational equivalence.

A function $f$ is invariant to a transformation $t$ if
$$
f(t(\mathbf{x}))=f(\mathbf{x}).
$$
A function $f$ is equivariant to a transformation $f$ if
$$
f(t(\mathbf{x}))=t(f(\mathbf{x})).
$$


>[!info] Convolution $\ast$
>The convolution $\ast$ on a 2D image $\mathbf{X}$ with a 2D kernel $\mathbf{W}$
>$$
>z_{ij}=(\mathbf{X}\ast \mathbf{W})=\sum_m \sum_n X_{i+m, j+m}W_{m,n}
>$$

## Pooling
Reduce dimensions while retaining information

**Max pool**: Take the max value
**Average pool**: Take the average value

![[Pasted image 20250922133035.png|300]]

>[!example]- CNN on MNIST
>- MNIST data: $28\times 28$ and 1 channel
>- First hidden layer: $28 \times 28$ pixels and 9 channels
>- Use $5 \times 5$ filters
>
>For convolutional weights tensor $\mathbf{W}\in\mathbb{R}^{w\times h \times c_{in} \times c_{out}}$
>$$
>h_{x, y, c_1}^{(j)}=\sigma\left(\sum_{c_0, m, n} h_{x+m, y+n, c_0}^{(j-1)} W_{m, n, c_0, c_1}+b_{c_1}\right)
>$$
>or
>$$
>\mathbf{h}_{\because, c_1}^{(j)}=\sigma\left(\sum_{c_0} \mathbf{h}_{,:, c_0}^{(j-1)} * W_{:,: c_0, c_1}+b_{c_1}\right)
>$$
>

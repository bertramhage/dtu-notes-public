## Generalisation error
We assume that there is an underlying *data generation distribution*
$$
(x_i,y_i)\sim p_D(x,y)
$$

For a loss $L$ the generatlisation error is given by
$$
E^{gen}=\mathrm{E}_{x,y\sim}[L(f_{\phi}(x),y)]=\int L(f_{\phi}(x),y)p_D(x,y) \, dxdy 
$$
$$
E^{gen}=\frac{1}{n}\sum_{i=1}^{n} L(f_{\phi}(x_i),y_i) \, 
$$
where $\left\{ (x_i,y_i) \right\}_{i=1}^n$ are sampled from $p_D$.

If we train model $f_{\phi(D)}$ on datasets $D=\left\{ (x_i,y_i) \right\}_{i=1}^n$ assuming a squared loss
$$
\begin{aligned}
&\mathrm{E}_D[E^{gen}]= \\
&\mathrm{E}_{x\sim p_D(x)}\left[\underbrace{ (\bar{y}(x)-\bar{f}_{\phi(D)}(x))^{2} }_{ Bias }+\underbrace{ Var_D[f_{\phi(D)}(x)] }_{ Variance }+\underbrace{ Var[y(x)] }_{ \text{Inherent variance in } p_D }\right]
\end{aligned}
$$

## Choosing complexity
We partition our dataset $D$ into three:
$$
D^{train}\cup D^{val}\cup D^{test}
$$
1. Train models with different hyperparameters on $D^{train}$
	$\hat{\phi}^{(j)}=\arg\min_\phi L(\phi, D^{train})$
2. Evaluate the performance on the validation set $D^{val}$
	$E^{val,(j)}=L(\hat{\phi}^{(j)}, D^{val})$
3. Select the model with the lowest validation error
	$\hat{j}=\arg\min_j E^{val, (j)}$
4. Estimate the generalisation error on the *test set*
	$E^{gen}\approx E^{test}=L(\hat{\phi}^{(\hat{j}),D^{test}})$
